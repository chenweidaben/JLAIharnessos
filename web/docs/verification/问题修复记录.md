## 逐项详情

### F1 `request.ts` 多余属性检查
- **现象**：`error TS2353: 'options' does not exist in type 'AxiosRequestConfig'`（4 处）。
- **根因**：`RequestConfig extends AxiosRequestConfig` 追加了业务自定义字段 `options?: RequestOptions` 与 `_retried`。axios 实例 `.request(config)` 形参类型为 `AxiosRequestConfig<D>`，对携带自定义字段的对象触发了多余属性检查。
- **修复**：get/post/put/del 四个方法在调用 `.request<ApiResponse<T>>(config as AxiosRequestConfig)`。响应拦截器本就通过 `response.config as RequestConfig` 读取 `options`/`_retried`，运行时行为不变。
- **风险**：低。仅类型层断言，不改运行时。

### F2 jsdom 缺失 URL 工厂
- **现象**：`Error: createObjectURL does not exist`（downloadBlob/exportCsv/exportJsonAsCsv 共 5 例）。
- **根因**：jsdom 未实现 `URL.createObjectURL`，`vi.spyOn(URL,'createObjectURL')` 因属性不存在而抛错。
- **修复**：在 `tests/setup.ts` 对 `URL.createObjectURL/revokeObjectURL` 做兜底实现（返回 `blob:mock-url` / no-op），各用例再用 `vi.spyOn().mockReturnValue(...)` 覆盖。

### F3 / F4 / F6 测试字面量与数据笔误
- 源码均符合业务规范，仅测试期望与实际 mock 不一致；已按“源码=规范”修正测试，避免为迁就错误测试而改动产品逻辑。

### F5 antd Empty SVG title 干扰
- antd `Empty` 简易插图为内嵌 SVG，其可访问性 `<title>` 文本与 description 同为“暂无数据”，导致 `getByText` 命中多节点。按描述容器选择器收窄查询。

### F7 / F8 孤儿模块接线
- 门诊与住院两套业务页面在前序并行开发中已完成（合计 20 个组件 + 2 个 store），但未挂入路由与菜单，用户无法到达。本次按组件实际读取的路由参数名接线（问诊 `:encounterId`、查房 `:patientId`）。

### F9 / F10 顶栏缺陷
- “个人中心”可点击但无行为；登出未清理 RBAC store。二者均影响实际使用，已修复。
