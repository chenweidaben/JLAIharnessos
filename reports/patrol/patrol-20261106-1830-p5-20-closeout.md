### 2. E2E fail-open 消除（commit `f08e8b72`）
**问题**：`BASE` 模块级默认 `http://127.0.0.1:8080`，spawn 失败时静默回落生产 BFF，假绿。

**修法**：
- `BASE: string | null = null`
- `requireBase()` 未初始化直接 throw
- `call()` 全部走 `requireBase()`
- `afterAll` 重置 `BASE = null`

**注入自证**：
| 场景 | 结果 |
|---|---|
| 注入 `spawn('bun-nonexistent')` | exit 1，`baseUrl not initialized`，23 用例全 fail |
| 恢复 `process.execPath` | exit 0，23 pass / 0 fail / 82 expect |

### 3. search indexCache 修复（commit `4cb895c6`）
根因：失效条件用 `index.length !== store.count()`（段数对比）。段数不变但内容变化时不重建，永远用空索引。
修法：按 `segmentId:segmentHash:toSeq` 签名比对。
注入自证：旧逻辑 22/1（P5-6 复现），新逻辑 23/0。
