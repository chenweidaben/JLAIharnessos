### 9.4 mirror 推送异常（已解决，记录现象）

首推 mirror 被 GitHub 拒绝，两种错误先后出现：

1. `remote: fatal error in commit_refs_rules` —— 服务端规则集报错；
2. `git@github.com: Permission denied (publickey)` —— 与直连 `ssh -T` 成功矛盾，443 端点亦失败，判断为 SSH 侧临时认证抖动/限流，非密钥损坏、非配置错误。

处置：退避 90 秒后用 `GIT_SSH_COMMAND='ssh -i C:/Users/lenovo/.ssh/id_ed25519 -o IdentitiesOnly=yes -o StrictHostKeyChecking=no'` 重推成功，并从 `80d36856` 推进到 `9c9b6d62`。远端另打印 `Changes must be made through a pull request` 属规则集提示，**ref 实际已更新**，以 `ls-remote` 为准。

**踩坑补充**：`GIT_SSH_COMMAND` 不跨 PowerShell 调用继承（每次调用是独立进程），设完变量与 push 必须在同一次调用内完成；`ls-remote` 失败不等于推送失败，必须重试读到 40 位 SHA 才算核对成立。
