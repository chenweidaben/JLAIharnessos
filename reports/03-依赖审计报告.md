# 健澜科技数智医院智能体 — 依赖安全审计报告

- 审计日期：2026-09-16
- 工具：后端 `bun audit`（bun 1.4.2）；前端 `npm audit --registry=https://registry.npmjs.org`

## 一、后端（bun audit）

### 修复前
46 个漏洞：**16 高危 / 27 中危 / 3 低危**。
高危集中在：
- `undici`（HTTP 客户端）：TLS 证书校验绕过、跨源路由、WebSocket DoS、缓存投毒等多条 GHSA。
- `ws`（WebSocket）：小分片内存耗尽 DoS、未初始化内存泄露。

### 修复动作
执行 `bun audit fix`，升级受影响包至范围内修复版本。
- 修复 **44** 个漏洞，覆盖 4 个包。
- 16 个高危**全部清零**。

### 修复后
**2 个中危**，均在 `@anthropic-ai/sdk@0.80.0`：
- 本地文件系统记忆工具文件权限不安全（>=0.79.0 <0.91.1）
- 记忆工具路径校验可逃逸到兄弟目录（>=0.79.0 <0.81.0）

> 该 SDK 受 package.json semver 范围锁定，升级至 >=0.91.1 需跨小版本并回归测试 AI 调用链。判定为中危、且为开发/集成期能力，记录为待办，不阻断本次交付。

## 二、前端（npm audit）

### 修复前
11 个漏洞：3 严重 / 2 高危 / 6 中危。

### 修复动作
执行 `npm audit fix`（非破坏性），修复 1 个。

### 修复后
**10 个漏洞**，按可触达性分类：

| 包 | 严重级 | 类别 | 是否进生产包 |
|---|---|---|---|
| vitest / @vitest/coverage-v8 / @vitest/ui / @vitest/mocker | 严重/中 | 测试工具 | 否（devDependencies） |
| vite / vite-node / esbuild | 高/中 | 构建/dev 服务器 | 否（devDependencies） |
| echarts | 中 | 运行时图表（XSS） | 是 |
| react-router / react-router-dom | 中 | 路由（开放重定向） | 是 |

**说明：**
- 标记"严重/高"的 vitest、vite、esbuild 均为**开发与测试工具链**，不进入生产 bundle，攻击面仅限本地开发服务器/测试进程。
- 生产相关两项：echarts（中危 XSS）、react-router（中危开放重定向/反序列化）。二者的修复均需跨大版本升级（react-router 6→7），涉及路由 API 变更，需专项回归。记录为待办，不阻断本次交付。

## 三、结论
- 后端**高危漏洞全部修复**；残留 2 个中危（SDK 版本锁定，待规划升级）。
- 前端**无生产路径高危/严重漏洞**；dev 工具链的严重/高危项不进生产包。
- 未使用依赖与 bundle 体积分析建议后续接 depcheck / rollup-bundle-analyzer 例行化。
