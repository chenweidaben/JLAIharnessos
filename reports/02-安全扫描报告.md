# 健澜科技数智医院智能体 — 安全扫描报告

- 审查日期：2026-09-16
- 范围：后端 `src/`、前端 `web/src/`、配置与环境文件

## 一、结论
未发现 SQL 注入、XSS、命令注入、硬编码真实密钥或敏感信息泄露的可利用漏洞。演示用 mock token 与占位符配置已确认不构成实际暴露。

## 二、分项扫描结果

### 1. SQL 注入
- 代码库无直连关系型数据库查询字符串拼接；查询层以参数化/对象模型方式组织。
- `src/security/input/InputValidator.ts` 内置 UNION 注入等检测规则。
- **结论：无 SQL 注入面。**

### 2. XSS
- 前端全量搜索 `dangerouslySetInnerHTML`、`innerHTML =`：**0 命中**。
- 用户/模型产出文本经 React 默认转义渲染；无富文本裸渲染。
- **结论：无 XSS 注入面。**

### 3. 命令注入
- 后端搜索 `child_process` / `exec` / `spawn`：**0 命中**（此前 grep 到的 `exec` 全部为 `regex.exec()`）。
- 无任何系统调用与用户输入拼接。
- **结论：无命令注入面。**

### 4. 硬编码密钥
- 搜索 `password/apiKey/secret` 字面量赋值：**0 命中**真实凭据。
- 唯一例外：`src/bff/routes/auth.ts` 演示 mock 登录返回固定 `bff-access-token` / `bff-refresh-token`，仅用于本地联调 mock，非真实密钥，生产应替换为真实鉴权。
- `.env.example` 全部为占位符；`.gitignore` 已覆盖 `.env*`，环境文件未入库。
- **结论：无硬编码真实密钥；mock token 已标注。**

### 5. 敏感信息泄露
- 出参/日志链路含脱敏组件（`DesensitizationEngine` / `DesensitizationUtils`），对身份证、手机号等做规则化遮蔽。
- 日志记录方法、路径、耗时、traceId，不记录密码/证件原文。
- 错误信息经统一错误模型返回，不暴露内部堆栈/路径。
- 前端未在 localStorage 存放敏感凭据（token 由 BFF 会话管理）。
- **结论：无敏感信息泄露。**

## 三、遗留观察项（非阻断）
| 项 | 位置 | 风险 | 建议 |
|---|---|---|---|
| mock 固定 token | bff/routes/auth.ts | 演示态，非生产 | 生产前替换为真实 OIDC/JWT |
| 脱敏规则分支 | DesensitizationUtils.applyRuleToValue | 维护性 | 规则表化（见质量报告） |

## 四、依赖侧安全
详见《依赖审计报告》。后端高危依赖漏洞已全部修复。
