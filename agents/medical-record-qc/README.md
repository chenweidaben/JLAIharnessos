# AI 病历质控智能体（medical-record-qc）

> 健澜科技杠OS · 十大刚需智能体之一
> 把质控员从"事后翻病历"变为"实时全量质控"。

## 解决的痛点

人工质控覆盖率低（通常<10%）、滞后、标准不一。本智能体对在院/出院病历做**全量、实时、一致**的内涵质控、病案首页质控与核心制度检查，服务电子病历分级评价与等级评审。

## 工作流

```
开始
 → foreach 病历：内涵质控(medical_record_quality_check) 逐份检查
 → 核心制度落实检查(core_system_check，科室+时间范围)
 → 病案首页质控(medical_record_front_page_check，失败不阻断)
 → 大模型汇总生成结构化质控报告(合格率/严重缺陷/共性问题/整改清单)
 → 是否存在严重缺陷？
     ├─ 是 → 质控科人工复核(human，分派责任科室与期限) → completed
     └─ 否 → 直接出报告
结束
```

## 输入

| 字段 | 说明 |
|------|------|
| `recordIds` | 待质控病历ID数组 |
| `department` | 科室（核心制度检查） |
| `timeRange` | 检查时间范围 `{from,to}` |
| `frontPage` | 病案首页数据（可选） |

## 输出

- `report`：合格率、严重/一般缺陷、共性问题、整改清单
- `perRecord`：逐份质控明细
- `review`：质控科复核结论（如有严重缺陷）

## 合规

缺陷判定可追溯到规则编号与病历位置；严重缺陷强制人工复核；全部审计留痕。
