# 医务统计与管理报表智能体（medical-affairs-report）

> 健澜科技杠OS · 十大刚需智能体之一
> 院/科两级报表自动生成，让管理用数据说话。

## 价值

并行汇聚医疗质量、科室运营、DRG/DIP、核心制度四类数据，自动生成管理报表，提炼 KPI、亮点、风险与改进建议；重大风险提交管理者复核，支撑精细化运营、等级评审与公立医院绩效考核。

## 工作流

```
开始
 → parallel：医疗质量指标 ‖ 科室运营 ‖ DRG/DIP ‖ 核心制度（4路并行）
 → 管理标准/评审要求 RAG
 → 大模型生成结构化报表(KPI/亮点/风险分级/改进建议/文字综述)
 → 存在重大风险？ ├ 是 → 管理者人工复核(分派责任与期限) → major_risk_reviewed
                  └ 否 → generated
结束
```

## 输入 / 输出

- 输入：`reportType`、`department`（科室/全院）、`timeRange`
- 输出：`report.kpis`、`highlights`、`risks`（高/中/低）、`recommendations`、`narrative`、`sources`（四类原始数据）

## 合规

- 所有结论以输入数据为依据，不编造数字，数据缺失明确标注；
- 区分数据事实与分析推断；
- 重大质量安全风险强制人工复核。
