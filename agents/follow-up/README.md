# 智能随访智能体（follow-up）

> 健澜科技杠OS · 十大刚需智能体之一
> 院外不断线，异常早发现。

## 价值

按病种随访方案为术后、出院及慢病患者**批量**生成个体化问卷并下发（短信/微信/App），回收后识别异常与红旗症状，异常自动预警、医护复核，形成院外连续管理闭环。

## 工作流

```
开始
 → foreach 患者：
     出院/病史(get_patient_history)
       → 随访方案 RAG
       → 大模型生成个体化问卷与红旗症状
       → 下发随访任务(follow_up_management)
 → 大模型汇总成功数与异常患者
 → 存在异常？ ├ 是 → 医护人工复核/安排复诊 → abnormal_reviewed
             └ 否 → dispatched
结束
```

## 输入 / 输出

- 输入：`patientIds`（批量）、`disease`（病种）、`channel`（下发渠道）
- 输出：`summary`（总数/已下发/异常数）、`abnormalPatients`、`details`（逐患者问卷）、`review`（医护处置）

## 安全

- 红旗症状从严识别并强制就医提示；
- AI 不调整处方药剂量；
- 患者语言通俗温和，异常由医护闭环。
