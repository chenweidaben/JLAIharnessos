### 2.2 CDS 规则分布（实际 43，版本 1.0.0）

|---|---|

### 3.1 Agent 主循环
- 覆盖用例：`MedicalAgentLoop / QueryEngine / LLMClient(Mock) / SystemPromptBuilder / ContextCompressor(四级) / SessionManager / TokenBudgetTracker / MedicalContextBuilder / AgentEventBus`。
- 结论：启动→接收输入→工具调用→流式→结束状态机闭环正常；Token 预算评估耗时 <5ms（性能用例）。

### 3.2 36 个医疗工具
- 每个工具均注册成功，具备 Zod `inputSchema` 与 `execute`；输入校验、正常流程（Mock 数据）、异常（权限不足/不存在）、风险分级、输出包装（`ToolResult{success,data,error}`）均有单测覆盖。
- 高风险写操作（create_order / create_prescription / cancel_order）强制 `doctor` 角色 + 二次确认 + CA 签名；药师类（prescription_audit / order_audit）角色隔离（护士不能代开处方、医生不能审自己处方，见 E2E scenario1/5）。

### 3.3 工具注册中心
- `createRegistryWithFirstBatch()` 注册 36 个；按名称查找、按分类筛选、`has/size`、重复注册抛错均验证。
