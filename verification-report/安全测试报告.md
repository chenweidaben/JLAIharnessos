### 修复记录

- **[P0] attachUser 不验签**：原代码任意非空 Bearer token 直接赋予 admin 角色。已重写为 HMAC-SHA256 JWT 验签，校验 exp/签名/时序安全比较。
- **[P0] WebSocket 无鉴权**：/ws/chat 升级前未校验 token。已增加 wsAuthorized() 校验。
- **[P1] /system/monitor 无角色控制**：原任何登录用户可查看运行指标。已增加 requireRole('admin')。
- **[P1] 缺少 /ready 探针**：已新增 /ready 公开就绪端点。

## 四、前端安全验证（第3步）

| 检查项 | 实现 | 结果 |
|--------|------|------|
| localStorage 不存密码 | 仅存混淆后 token，密码仅内存 | ✓ |
| dangerouslySetInnerHTML | 全局搜索 0 处 | ✓ |
| XSS 防护 | React 默认转义 | ✓ |
| Token 存储 | localStorage + XOR/Base64 混淆（文档标注为演示态） | △ |
| 文件上传 | 头像上传 beforeUpload return false（纯演示，不上传） | ✓ |
| CSRF 防护 | 双重提交 Cookie + X-CSRF-Token 头 | ✓（新增） |
| 安全响应头 | CSP/X-Frame-Options/nosniff/HSTS/Referrer-Policy | ✓（新增） |
| 路由懒加载 | 全部页面 React.lazy + Suspense | ✓ |

> **说明**：Token 存于 localStorage 而非 HttpOnly Cookie，在纯 SPA + Bearer Token 模式下可接受（CSRF 不适用），生产环境建议切换为 HttpOnly Cookie + SameSite=Strict。
