## 一、测试策略概述

### 1.1 测试金字塔

本项目采用**测试金字塔**分层策略：

```
            /\
           /  \    E2E 场景测试（5 场景 26 用例）
          /----\
         /      \   集成测试（integration/ 适配器/总线/协议）
        /--------\
       /          \  单元测试（主力，898 + 157 用例）
      /------------\
```

### 1.2 Mock 策略

| 层 | Mock 方式 |
|----|-----------|
| LLM 调用 | LLMClient Mock 模式（确定性响应） |
| HIS/EMR/LIS/PACS | Mock 适配器（内存种子数据） |
| 数据库 | 内存种子数据 + LRU Cache |
| 向量检索 | Mock Embedding + 本地向量库 |
| 前端 | Vitest + jsdom + Mock store |

### 1.3 CI 集成

- 后端：`bun test` + `bun test --coverage` + `tsc --noEmit`
- 前端：`vitest run` + `tsc --noEmit` + `vite build`
- 覆盖率门禁：后端行覆盖率 ≥85%
