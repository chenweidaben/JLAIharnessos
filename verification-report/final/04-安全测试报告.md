## 三、安全架构概述

| 安全域 | 实现 |
|--------|------|
| 认证 | JWT（HMAC-SHA256）+ accessToken/refreshToken 双令牌 |
| 授权 | RBAC（12 角色）+ ABAC + 数据范围（4 级）+ 三级风险确认 |
| 加密 | AES-256-GCM 认证加密 + 双层密钥体系 + PBKDF2/bcrypt 密码哈希 |
| 审计 | 六类日志 + 哈希链防篡改 + 180 天保留 |
| 防护 | 限流（300 次/分钟/IP）+ CSRF 双重提交 + 安全响应头 + Prompt 注入检测 + 输入白名单 |

## 八、安全漏洞修复记录（5 个 P0 漏洞）

| # | 漏洞 | 风险 | 修复方案 | 状态 |
|---|------|------|----------|------|
| 1 | JWT 不验签，任意 token 即 admin | 攻击者构造任意字符串即获 admin 权限 | HMAC-SHA256 验签 + exp 校验 + 时序安全比较 | ✅ 已修复 |
| 2 | 错误信息泄露内部细节 | 泄露 SQL/路径/堆栈，辅助攻击 | 5xx 统一文案 + traceId | ✅ 已修复 |
| 3 | WebSocket 无鉴权 | 任意客户端连接接收告警推送 | 升级前 wsAuthorized() 校验 token | ✅ 已修复 |
| 4 | 缺安全响应头 / CSRF | 缺少 XSS/点击劫持防护 | 新增 securityHeaders.ts + csrf.ts | ✅ 已修复 |
| 5 | /system/monitor 无角色控制 | 任意登录用户查看系统运行指标 | requireRole('admin') 守卫 | ✅ 已修复 |

**P1 安全加固（4 项，全部修复）**：WebSocket 鉴权、安全响应头、CSRF 防护、/system/monitor 角色控制、/ready 就绪端点。
