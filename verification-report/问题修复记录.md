## 详细修复记录

### FIX-001：前端离线状态指示器（P1）

**问题**：网络断开时前端无任何提示，用户提交数据可能静默失败。

**根因**：项目未监听 `window.addEventListener('online'/'offline')`，也无 `navigator.onLine` 状态管理。

**修复**：
1. 新建 `web/src/hooks/useOnlineStatus.ts`：监听 online/offline/visibilitychange 事件，返回布尔在线状态。
2. 新建 `web/src/components/common/OfflineIndicator.tsx`：断网时顶部红色 Alert 横幅（"网络已断开，数据不会自动同步"），恢复后短暂绿色提示"网络已恢复"。
3. 在 `hooks/index.ts` 与 `components/common/index.ts` 导出。
4. 在 `AppLayout.tsx` 的 Content 区挂载 `<OfflineIndicator />`。

**验证**：`npx tsc --noEmit` 通过。

---

### FIX-002/003：请求超时与重试增强（P2）

**问题**：超时 15s 硬编码；5xx 仅 GET 重试 1 次无退避；离线时仍重试。

**修复**（`web/src/services/request.ts`）：
- 超时改为 `Number(import.meta.env.VITE_API_TIMEOUT_MS ?? 30_000)`
- 新增 `backoffDelay(attempt)`：指数退避，上限 8s
- 新增 `isOnline()` 判断，离线不重试
- 重试条件：GET + (500-504 或网络错误) + 在线 + 未超 2 次
- ECONNABORTED 提示"请求超时"
- POST/PUT/DELETE 不自动重试（避免重复提交医嘱/处方）

**验证**：typecheck 通过。

---

### FIX-004：icons.tsx 类型导入修复（P2）

**问题**：`import { type AntdIconProps } from '@ant-design/icons'` 报错 TS2614，AntD5 未导出该类型。

**修复**：移除该导入，内联定义：
```ts
export type AntdIconProps = { className?: string; style?: CSSProperties; spin?: boolean };
```

**验证**：`npx tsc --noEmit` EXIT 0。
