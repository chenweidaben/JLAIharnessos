# 项目总览

> 健澜科技数智医院智能体 · 项目全景说明
> 版本 v1.0 ｜ 2026-09

## 1. 项目背景和目标

在医院高质量发展与"AI 原生医院"趋势下，临床医生面临病历书写负担重、诊疗决策信息分散、质控与合规要求高等痛点。本项目目标是打造一款嵌入临床工作流、安全可控、可与现有医院信息系统无缝集成的 AI 智能体，把医生从重复劳动中解放出来，并以 CDS 保障医疗安全。

## 2. 产品定位

面向院内临床场景的**医疗领域 AI 智能体底座与应用**：既提供终端交互（TUI），也提供服务端 API，可作为未来 Web/移动端的统一后端。

## 3. 核心价值

- 提效：AI 辅助病历、医嘱、问诊，缩短文书时间；
- 提质：CDS 实时拦截高危用药与漏诊风险；
- 合规：分级分类、脱敏、审计全链路可追溯；
- 集成：不替换现有 HIS/EMR/LIS/PACS，做增量智能层。

## 4. 功能矩阵

| 域 | 能力 |
| --- | --- |
| 患者管理 | 查询、详情、就诊史 |
| 电子病历 | 读取、AI 生成、问答、模板 |
| 医嘱管理 | 列表、开立、作废、审核 |
| 处方药品 | 处方开立/审核/查询、药品信息 |
| 检验检查 | 结果/报告查询、检验与影像申请、DICOM 调阅 |
| 临床决策支持 | 相互作用、诊断/治疗建议、危急值 |
| 质控管理 | 运行病历质控、首页质控、核心制度 |
| 患者服务 | 预约挂号、就诊提醒、随访 |
| 运营管理 | 科室运营、质量指标、DRG/DIP |
| 系统集成 | HIS/EMR 同步、HL7 消息 |

## 5. 技术架构总览

```
终端/浏览器 → 反向代理 → 应用层(Bun, Agent 循环)
                          ├ 工具层(36 医疗工具, 三级风险确认)
                          ├ 智能体层(主代理 + 8 科室子代理 + 编排)
                          ├ 知识层(RAG 检索 + CDS 规则引擎)
                          ├ 安全层(认证/权限/审计/加密/脱敏/分级)
                          └ 集成层(HIS/EMR/LIS/PACS, HL7/FHIR/DICOM)
数据层: PostgreSQL+pgvector / Redis / MinIO
```

## 6. 模块关系图

- `core/`：引擎底座（agent/tools/session/context/coordinator/buddy）；
- `medical-tools/`：业务能力单元，依赖 `core/tools` 与 `security`；
- `knowledge/`：RAG 与 CDS，供工具与主代理调用；
- `security/`：横切安全，贯穿所有工具执行；
- `integration/`：对外系统适配，供集成类工具调用；
- `ui/`：终端交互，调用核心服务。
