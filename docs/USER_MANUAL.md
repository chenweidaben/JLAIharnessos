## 1. 手册说明

本手册按角色组织，覆盖 **医生 / 护士 / 药师 / 管理员 / 患者** 五类用户。
前三章（登录、工作台、数据安全）对所有角色通用；之后各章节仅对对应角色开放。

- 在线版：前端页面「帮助中心 → 操作手册」，支持角色切换与步骤导航。
- 接口版：`GET /api/v1/help/manual?role=doctor`，返回结构化手册（目录 + 章节 + 步骤）。
- 视觉规范：深海蓝 VI，主色 `#0A4D8C`。

## 2. 全员通用

### 2.1 登录与账号

1. **打开登录页**：浏览器输入院内工作台地址，或打开患者端小程序/APP；员工使用「员工登录」，患者使用「患者登录」。
2. **输入凭证**：员工输入工号 + 初始密码；患者输入手机号 + 短信验证码，或医保电子凭证扫码登录。
3. **首次登录改密**：首次登录强制修改初始密码（8 位以上，含大小写与数字），并完成手机绑定用于 MFA。
4. **忘记密码**：员工经科室管理员重置初始密码；患者通过绑定手机短信自助重置。

> ⚠️ 严禁共用账号、严禁在私人设备保存密码。连续 5 次密码错误将锁定账号 15 分钟。

### 2.2 工作台概览

1. **认识布局**：左侧业务导航，顶部搜索与消息铃铛，中部待办卡片，右侧 Personal Agent 对话入口。
2. **处理待办**：点击待办卡片直接进入对应业务单据。
3. **使用 Personal Agent**：自然语言下达指令（如「帮我写一份入院记录」），Agent 调起业务模块并回填草稿。
4. **切换视图**：员工切换门诊 / 住院 / 管理视图；患者在「我的」页管理就诊人。

> ⚠️ 离开工位请立即锁屏（Win+L），患者数据不得在公共屏幕久留。

### 2.3 数据安全与隐私

1. **最小必要访问**：仅查看本科室或被授权患者；跨科会诊走授权申请，到期自动回收。
2. **导出与外发**：病历、报告导出需审批；严禁通过私人微信/邮箱外发患者数据。
3. **操作留痕**：登录、查看、修改、导出均写入审计日志，只读不可篡改。
4. **异常上报**：发现账号异常或数据泄露迹象，立即锁屏并上报信息科安全值班。

## 3. 医生手册

### 3.1 门诊接诊

1. **叫号接诊**：门诊工作站按叫号顺序接诊，点击患者姓名进入接诊单。
2. **书写病历**：口述生成门诊病历草稿，核对主诉、现病史、查体、诊断后签名。
3. **开具检查检验**：按诊断开具申请单；Agent 给出合理用药与检查建议，确认后一键带入。
4. **提交并打印**：确认收费类别（医保/自费）后提交，患者缴费后生效。

### 3.2 住院管床

1. **查看管床列表**：住院视图按床号查看本人管床患者；异常检验值置顶标红。
2. **查房记录**：Agent 汇总「昨夜至今晨变化」生成病程草稿，核对后签名。
3. **开具医嘱**：开立长期/临时医嘱，系统自动做相互作用、剂量、过敏筛查。
4. **危急值处理**：危急值弹窗在规定时限内查看、复述、处理签名，形成闭环。

> ⚠️ 精麻毒药品医嘱需双签并核对患者身份证。危急值未闭环前不得下班。

### 3.3 处方开具与审方

1. **开具处方**：选择药品、剂量、用法、疗程；Agent 自动校验相互作用与过敏史。
2. **处理拦截**：红色拦截按建议调整；确需保留的填写理由并提交药师人工干预。
3. **提交审方**：审核未通过退回「待修改」，按意见修改后重提。

### 3.4 病历书写与签名

1. **按时限书写**：入院记录 24 小时内、首次病程 8 小时内完成。
2. **AI 草稿核对**：逐条核对主诉、查体、诊断与医嘱一致性，不得直接采纳。
3. **三级签名**：住院医师 → 主治医师 → 主任医师逐级电子签名。
4. **质控整改**：退回的缺陷项在规定时限内整改重提。

## 4. 护士手册

### 4.1 床边交班（SBAR）

1. **生成交班单**：按 SBAR（现状-背景-评估-建议）自动生成草稿。
2. **床边核对**：与下一班护士共同核对患者身份、管路、皮肤、特殊用药。
3. **双签名**：交接双方电子签名；危急值、特殊管路高亮，漏交被拦截提醒。

### 4.2 护理记录录入

1. **录入生命体征**：按测量时间录入体温、脉搏、呼吸、血压；支持手持终端自动采集。
2. **记录护理措施**：录入用药、输液、皮肤护理、病情观察；Agent 草稿核对后签名。
3. **体温单回传**：体温单数据自动汇总，异常值自动标红。

### 4.3 医嘱执行与三查七对

1. **核对医嘱**：执行队列核对患者、药品、剂量、用法、时间。
2. **扫码确认**：扫描腕带与药品条码，系统比对一致后允许执行。
3. **记录执行**：给药后实时记录时间、执行人、滴速；皮试结果按时限回填。

> ⚠️ 皮试结果未回填不得执行后续用药。

## 5. 药师手册

### 5.1 处方审核

1. **打开审方队列**：按时间先后处理，急诊处方优先。
2. **核对要点**：诊断与用药一致性、剂量、疗程、相互作用、过敏史、重复用药。
3. **通过或退回**：合理处方通过；不合理处方退回并填写意见。
4. **特殊管理药品**：精麻毒药品单独审核，核对身份证、处方权资质与极量。

### 5.2 药品调配与发药

1. **接收调配单**：按货位拣药，近效期优先。
2. **扫码核对**：逐盒扫描条码与处方条码，不一致拦截。
3. **发药与交代**：核对取药号/身份证，当面交代用法用量、储存条件与不良反应。

### 5.3 不良反应（ADR）上报

1. **收集病例**：记录用药与反应时间线。
2. **填写报告**：在 ADR 模块填写患者信息、怀疑药品、反应表现、处理与转归。
3. **随访归档**：跟踪转归，报告归档至药学部与国家监测系统。

> ⚠️ 严重 ADR 15 日内、死亡病例立即上报。

## 6. 管理员手册

### 6.1 账号与权限配置

1. **新增账号**：录入工号、姓名、科室、角色模板；新账号默认本科室只读。
2. **分配权限**：业务权限走申请审批流；跨科授权设有效期，到期自动回收。
3. **停用与解锁**：离职立即停用账号；安全确认后解锁锁定账号。
4. **维护数据字典**：双人复核后发布变更。

### 6.2 运行监控与告警

1. **查看监控大盘**：每日早高峰前查看 P95 耗时、5xx 错误率、Agent 队列、连接池。
2. **处理告警**：红色阈值按指引扩容/限流/回滚；变更走变更登记。
3. **巡检日志**：每日巡检错误日志与慢查询，形成运维日报。

### 6.3 审计日志与合规

1. **检索日志**：按人、时间、操作类型、患者号组合检索。
2. **调查越权**：对越权尝试、异常导出形成调查报告。
3. **导出留证**：配合监管检查时导出指定时段日志，导出动作本身也写入审计。

## 7. 患者手册

### 7.1 挂号与预约

1. **选择科室医生**：小程序「挂号」页选择院区、科室、医生、日期。
2. **确认就诊人并支付**：选择就诊人，支持医保移动支付。
3. **到院签到**：提前 15 分钟自助机或小程序签到取号。
4. **退号改约**：就诊前一日 24:00 前自助退号退款。

### 7.2 报告查询与缴费

1. **查看报告**：「报告」页查看检验检查结果；危急值弹窗提示复诊。
2. **在线缴费**：「缴费」页查看清单，支持医保个账与微信/支付宝。
3. **下载电子票据**：「票据」页下载电子发票用于报销。

### 7.3 在线咨询与随访

1. **发起咨询**：选择就诊过的医生，发送症状描述与照片。
2. **接收随访**：出院后接收随访问卷与用药提醒，按时填写。
3. **预约复诊**：医生建议复诊时直接点入复诊号源。

> ⚠️ 在线咨询不替代急诊；出现胸痛、呼吸困难等急症请立即拨打 120。
