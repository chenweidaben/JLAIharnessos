## 1. 环境准备

### 1.1 操作系统初始化

```bash
# 创建运行用户
sudo useradd -m -s /bin/bash jianlan
# 设置时区与时间同步
sudo timedatectl set-timezone Asia/Shanghai
sudo systemctl enable --now chronyd
# 关闭不必要服务、配置防火墙白名单（见部署架构端口规划）
```

### 1.2 安装运行时

```bash
# 安装 Bun（>=1.3.0）
curl -fsSL https://bun.sh/install | bash
bun --version   # 应输出 >=1.3.0

# Node.js >=18（部分工具依赖）
# 使用 nvm 或官方源安装，略
```

### 1.3 网络配置

- 配置医院内网 DNS；
- 在集成总线白名单中登记本应用出口 IP；
- 与 HIS/EMR/LIS/PACS 厂商确认接口地址与鉴权方式。

## 2. 数据库部署（PostgreSQL + pgvector）

```bash
# 安装 PostgreSQL 16
sudo dnf install -y postgresql-server postgresql-contrib
sudo postgresql-setup --initdb
sudo systemctl enable --now postgresql

# 安装 pgvector 扩展
sudo dnf install -y pgvector_16
```

初始化数据库与扩展：

```sql
CREATE DATABASE jianlan_agent ENCODING 'UTF8';
\c jianlan_agent
CREATE EXTENSION IF NOT EXISTS vector;
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";
```

初始化表结构与种子数据（按项目 `sql/` 目录脚本顺序执行）：

```bash
psql -U postgres -d jianlan_agent -f sql/01_schema.sql
psql -U postgres -d jianlan_agent -f sql/02_seed_catalog.sql
```

备份配置（`postgresql.conf` 关键项）：

```
wal_level = replica
archive_mode = on
archive_command = 'cp %p /backup/pgwal/%f'
max_wal_senders = 5
```

## 3. 缓存部署（Redis）

```bash
sudo dnf install -y redis
sudo systemctl enable --now redis
redis-cli ping   # 应返回 PONG
```

关键配置（`redis.conf`）：

```
bind 127.0.0.1
requirepass <强随机密码>
maxmemory 4gb
maxmemory-policy allkeys-lru
```

## 4. 对象存储部署（MinIO）

```bash
wget https://dl.min.io/server/minio/release/linux-amd64/minio
sudo install -m 755 minio /usr/local/bin/
mkdir -p /data/minio
export MINIO_ROOT_USER=admin
export MINIO_ROOT_PASSWORD=<强密码>
minio server /data/minio --address :9000 --console-address :9001
```

创建 bucket：`medical-docs`、`knowledge-raw`、`audit-archive`（经 `mc mb`）。

## 5. 应用部署

```bash
# 5.1 获取代码
git clone https://git.jianlan.tech/medical/jianlan-medical-agent.git
cd jianlan-medical-agent

# 5.2 安装依赖（packageManager: bun@1.3.11）
bun install

# 5.3 配置环境变量
cp .env.example .env
# 编辑 .env：DATABASE_URL / REDIS_URL / MINIO_* / LLM_API_KEY / 集成适配器配置

# 5.4 类型检查与构建
bun run typecheck
bun run build        # 产出 dist/cli.js 与 dist/server.js

# 5.5 启动服务端
bun dist/server.js   # 等价 start:server
```

以 systemd 托管（`/etc/systemd/system/jianlan-agent.service`）：

```ini
[Service]
WorkingDirectory=/opt/jianlan-medical-agent
ExecStart=/usr/local/bin/bun dist/server.js
EnvironmentFile=/opt/jianlan-medical-agent/.env
Restart=always
User=jianlan
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now jianlan-agent
```

## 6. 反向代理配置（Nginx）

```nginx
server {
  listen 443 ssl;
  server_name agent.hospital.local;

  ssl_certificate     /etc/pki/tls/certs/jianlan.crt;
  ssl_certificate_key /etc/pki/tls/private/jianlan.key;

  location / {
    proxy_pass http://127.0.0.1:8080;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_read_timeout 300s;   # LLM 长连接
  }
}
```

## 7. SSL 证书配置

- 院内 CA 签发或商业证书；证书私钥权限 `600`，仅 root 可读。
- 配置 OCSP stapling 与 TLS1.2/1.3  only。
- 证书到期前 30 天告警（见告警手册）。

## 8. 验证部署

### 8.1 健康检查

```bash
curl -s http://127.0.0.1:8080/health   # 应返回 {"status":"ok"}
```

### 8.2 功能验证

- 登录医生账号，确认会话建立；
- 执行 `query_patient` 等只读工具，验证 PostgreSQL/Redis 连通；
- 验证 CDS 规则加载与 RAG 知识库可检索；
- 验证 HIS/EMR/LIS/PACS 适配器 `healthCheck()`。

### 8.3 性能验证

- 压测登录与只读工具接口，P95 响应 < 500ms（不含 LLM）；
- LLM 接口端到端 < 8s（视模型）。

## 9. 常见问题排查

| 现象 | 排查方向 |
| --- | --- |
| 应用无法启动 | 查看 `.env` 是否缺项；`bun run typecheck`；端口占用 |
| 数据库连接失败 | 检查 `DATABASE_URL`、pg_hba、pgvector 扩展是否安装 |
| Redis 认证失败 | 核对 `requirepass` 与 `REDIS_URL` |
| 知识库检索为空 | 确认已执行知识入库；向量维度与模型一致 |
| HIS 接口超时 | 集成总线白名单、厂商接口、防火墙 |

> 详细故障处置见 [故障排查手册](../operations/03-故障排查手册.md)。
