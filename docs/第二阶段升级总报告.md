### ③ 高并发韧性层（医院高并发技术对应）
新增 `src/resilience/` 六大生产级原语（纯内存、时钟可注入、统一 `MedicalAgentError`）：
- **CircuitBreaker**：closed/open/half-open 三态，连续失败 + 滚动错误率双阈值跳闸，冷却后半开探测自动恢复，fail-fast。
- **Bulkhead**：按资源隔离并发，reject/queue 双策略。
- **ConcurrencyLimiter**：异步信号量（FIFO 等待 + 获取超时）。
- **AsyncQueue**：有界队列，worker 并发 + 上限 + 满策略（reject/drop-newest/drop-oldest/backpressure）——面向检验结果批量推送、危急值扇出。
- **TieredRateLimiter**：进程内多维分级限流（租户:路由:用户 key，滑动窗口/令牌桶）。
- `cache/RateLimiter.ts` 加法扩展 sliding-window / token-bucket（向后兼容）。

**压测真实数据**（`scripts/loadtest.ts`，进程内压测）：
- 正常负载：**P50 27.6ms / P95 32.6ms / P99 34.1ms，2807 req/s**，熔断保持 closed。
- 故障注入：下游 60% 失败 → 熔断跳闸，**1899 次快速拒绝（P50≈0ms）**，保护下游不被打穿。
- 队列削峰：灌入 5000 条回推，**22500 req/s**，drop-oldest 保护在途任务。
- 开发中修复 2 个真实 BUG：信号量 release 重复计数、队列满用例时序失真。

### ④ 权限运行时可配置化（RBAC + ABAC，可管理可配置）
- 新增 `PermissionConfigStore.ts`：在静态权限矩阵之上做**可编辑 overlay**（版本号 + 变更审计 + 原子快照 + 并发安全）。
- 新增 `AdminPermissionService.ts` + `bff/routes/admin/permissions.ts`：GET matrix/roles、PUT entry、POST/DELETE grant。
- **零回归红线**：overlay 为空时返回静态基线同一引用，`evaluate` 完全委托既有 `PermissionChecker`。
- **医疗红线**：写操作二次校验 SYSTEM_ADMIN（越权→403）；已强制 MFA 的高风险条目只允许增强、不允许降级；每次变更全审计。
- 数据范围细化到科室/病区（`roleScopes`）。26 个新用例。

### ⑤ 多租户 / 一院多区
- 新增 `src/tenant/`：`TenantService`（内存注册表）、`TenantContextResolver`（`X-Tenant-Id`/`X-Campus-Id` 头 → JWT → 默认租户）、`DataScopeGuard`（行级隔离谓词）。
- 模型：**hospital → campus 两级**；软删除；默认医院保护（不可停用/删除防锁死）；级联软删院区。
- **隔离红线**：所有行必带 `tenantId` 谓词，指定校区再叠加 `campusId`；**fail-closed**（无租户标记不可见）；停用/软删租户立即拒绝。
- **运行验证**：无租户头 → 默认租户回退（200，33 技能）；未知租户头 → **403 隔离**。35 个新用例。

### ⑧ SKILLS 技能包体系（创新方向）

- 三个用户点名刚需做成标杆并**真实可跑**（真实 DeepSeek，日志 `artifacts/skill-e2e.log`）：

- 创新技能已落地：一院多区/多租户管理、低代码技能编排器、智能体工厂、角色权限可配置、技能市场。
