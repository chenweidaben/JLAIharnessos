## 二、前后端数据模型对比

### 2.1 一致项 ✅

| 模型 | 前端 | 后端 | 结论 |
|------|------|------|------|
| Gender | `'male'\|'female'\|'unknown'` | `'male'\|'female'\|'unknown'` | ✅ 一致 |
| ID | `string` | `string` | ✅ 一致 |
| 分页 PageQuery | `{page,pageSize,keyword?}` | BFF query 参数 | ✅ 一致 |
| 统一响应信封 | `{code,message,data}` | `{code,message,data,traceId}` | ✅ 已补 traceId |

### 2.2 差异项（需BFF适配器映射）⚠️

| 领域 | 前端字段 | 后端字段 | 差异 | 处置 |
|------|----------|----------|------|------|
| 生命体征 | `heartRate` | `pulse` | 字段名不同 | BFF映射 |
| 生命体征血压 | `systolic`+`diastolic`(number) | `bloodPressure`(string "120/80") | 结构不同 | BFF映射 |
| 生命体征时间 | `measureTime` | `measuredAt` | 字段名不同 | BFF映射 |
| 就诊类型 | `type:'inpatient'\|'outpatient'\|'emergency'` | `visitType: 6种` | 枚举不同 | BFF映射 |
| 就诊科室 | `deptName` | `department` | 字段名不同 | BFF映射 |
| 就诊状态 | `'ongoing'\|'finished'` | `'waiting'\|'in_progress'\|'completed'\|'cancelled'\|'transferred'` | 枚举不同 | BFF映射 |
| 检验项编码 | `itemCode` | `testCode` | 字段名不同 | BFF映射 |
| 检验项名称 | `itemName` | `testName` | 字段名不同 | BFF映射 |
| 检验参考范围 | `refRange` | `referenceRange` | 字段名不同 | BFF映射 |
| 检验异常标识 | `level: MedicalLevel` | `abnormalFlag: LabAbnormalFlag(7种)` | 枚举粒度不同 | BFF映射 |
| 医嘱类型 | `OrderType: 5种` | `OrderType: 10种` | 枚举粒度不同 | BFF映射 |
| 医嘱状态 | `'pending'\|'executing'\|'finished'\|'cancelled'` | `OrderStatus: 7种` | 枚举不同 | BFF映射 |
| 处方状态 | `'draft'\|'confirmed'\|'dispensed'` | `PrescriptionStatus: 7种` | 枚举不同 | BFF映射 |

> 说明：前端为面向UI的精简视图模型，后端为面向业务的完整领域模型。两者定位不同属正常，**必须在 BFF 聚合层做显式映射**，禁止前端直接消费后端领域模型。当前 BFF 种子数据已对齐前端 Patient 视图模型。

## 三、API 接口一致性

### 3.1 已修复的P0问题 ✅

| 编号 | 问题 | 修复 |
|------|------|------|
| API-01 | 前端 baseURL=`/api`，调用 `/auth/login` → `/api/auth/login`；Vite代理 strip `/api` → `/auth/login`；后端服务 `/api/v1/auth/login`，路径不匹配 | baseURL 改为 `/api/v1`，Vite 代理移除 rewrite，路径透传 |
| API-02 | Vite 代理目标端口 8787，后端实际监听 8080 | 代理 target 改为 `http://127.0.0.1:8080` |
| API-03 | 后端 `/api/v1/patients` 返回 `{list,total,pageSize,...}`，前端 `get<Patient[]>('/patients')` 期望数组 | 后端改为直接返回 `Patient[]`（客户端分页） |
| API-04 | 后端登录返回 `{accessToken,refreshToken,expiresIn,tokenType,user:{id,name,roles}}`，前端期望 `{tokens:{...},user:UserInfo}` | 后端对齐为 `{tokens:{accessToken,refreshToken,expiresIn}, user:{完整UserInfo}}` |
| API-05 | 前端 `fetchProfile` 调用 `/auth/profile`，后端仅有 `/auth/userinfo` | 后端 `/auth/profile` 与 `/auth/userinfo` 均返回 VIEW_USER |
| API-06 | 后端种子 `gender:'男'`，前端枚举 `'male'` | 改为 `gender:'male'` 并补全 Patient 视图字段 |
