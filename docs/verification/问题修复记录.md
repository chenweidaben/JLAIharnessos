## 已修复问题明细

### FIX-01 [P0] API 路径前缀不匹配
- **现象**：前端 `baseURL=/api` 调用 `/auth/login` → `/api/auth/login`；Vite 代理 strip `/api` → `/auth/login`；后端服务 `/api/v1/auth/login`。前端非 Mock 模式下全部 404。
- **根因**：前后端 API 版本前缀未对齐。
- **修复**：
  - `web/src/utils/config.ts` 默认 `apiBaseUrl` 改为 `/api/v1`
  - `web/.env.development` / `.env.production` 的 `VITE_API_BASE_URL` 改为 `/api/v1`
  - `web/vite.config.ts` 移除 proxy rewrite，路径透传
- **验证**：前端调用 `/api/v1/auth/login` → 代理透传 → `http://127.0.0.1:8080/api/v1/auth/login` ✅

### FIX-02 [P0] 代理端口错误
- **现象**：Vite 代理 target `127.0.0.1:8787`，后端 Bun 服务监听 `8080`。
- **修复**：`vite.config.ts` proxy target 改为 `http://127.0.0.1:8080`，WS 代理改为 `ws://127.0.0.1:8080`。

### FIX-03 [P0] 患者列表响应结构不匹配
- **现象**：后端 `/api/v1/patients` 返回 `{list,total,page,pageSize,totalPages}`，前端 `fetchPatients(): Promise<Patient[]>` 期望数组，运行时拿到对象导致表格崩溃。
- **修复**：`src/bff/routes/patient.ts` 改为 `ok(list)` 直接返回数组（前端 Table 客户端分页）。

### FIX-04 [P0] 登录响应结构不匹配
- **现象**：后端返回 `{accessToken,refreshToken,expiresIn,tokenType,user:{id,name,roles}}`，前端 `LoginResponse` 期望 `{tokens:{accessToken,refreshToken,expiresIn}, user:UserInfo}`。
- **修复**：`src/bff/routes/auth.ts` 引入 `VIEW_USER` 常量（对齐前端 UserInfo），login/refresh 返回 `{tokens:{...}, user:VIEW_USER}`。

### FIX-05 [P0] 后端种子数据性别枚举错误
- **现象**：种子 `gender:'男'`，前端枚举 `'male'|'female'|'unknown'`，性别列渲染错误。
- **修复**：`src/bff/aggregators/patient360Aggregator.ts` 改为 `gender:'male'`，并补全 `patientNo/birthDate/idCardMasked/phoneMasked/deptName/careLevel/allergies` 字段对齐前端 Patient 视图模型。

### FIX-06 [P0] a11y.tsx 类型构建错误
- **现象**：`import { KeyboardEvent } from 'react'` 与 `addEventListener('keydown', handler)` 期望的 DOM KeyboardEvent 冲突，`tsc --noEmit` 报错 4 处。
- **修复**：`web/src/utils/a11y.tsx` 引入 `ReactKeyboardEvent` 用于合成事件，定义 `DomKeyboardEvent = globalThis.KeyboardEvent` 用于原生监听。
- **验证**：`npx tsc --noEmit` 通过 ✅

### FIX-07 [P1] 患者列表无加载/错误/空状态
- **现象**：`fetchPatients().then(setPatientList)` 无 loading、无 catch、表格空数据无友好提示。
- **修复**：`web/src/pages/patients/index.tsx` 增加 `loading` 状态 + `<Spin>`、catch 错误 message、`<EmptyState>` 空状态、组件卸载保护 `alive`。

### FIX-08 [P1] 患者列表搜索框无功能
- **现象**：`Input.Search` 无 onSearch/onChange。
- **修复**：绑定 `keyword` state + `useMemo` 前端过滤（住院号/姓名/诊断）。

### FIX-09 [P1] 错误码枚举前后端不一致
- **现象**：前端 `ApiErrorCode` 用 HTTP 码（401/403/404/500）+ 1001/1002，后端用业务码（40100/40101/40300/40400/50000）。
- **修复**：
  - `web/src/types/api.ts` 枚举对齐后端业务码
  - `web/src/services/request.ts` 分离 `HTTP_STATUS` 常量与业务码，新增业务层 40100/40101 处理

### FIX-10 [P1] timestamp 类型不一致
- **现象**：前端 `timestamp?: number`，后端 `timestamp: string`（ISO）。
- **修复**：前端 `ApiResponse.timestamp` 改为 `string`，补 `traceId?`。

### FIX-11 [P1] 缺少 prefers-reduced-motion
- **现象**：无动画降级，违反 WCAG 2.1 AA。
- **修复**：`web/src/styles/animations.css` 增加 `@media (prefers-reduced-motion: reduce)` 全局降级。
