# 备份恢复手册

> 健澜科技数智医院智能体 · 数据保护与灾难恢复
> 版本 v1.0 ｜ 2026-09

## 1. 备份策略

| 策略 | 说明 | 适用对象 |
| --- | --- | --- |
| 全量备份 | 完整拷贝 | 数据库、对象存储，每日/每周 |
| 增量备份 | 仅变化块 | 数据库（WAL） |
| 差异备份 | 相对上次全量的差异 | 配置与日志 |

## 2. 备份内容

| 内容 | 方式 |
| --- | --- |
| PostgreSQL 业务与向量数据 | `pg_dump` + WAL 归档 |
| Redis 会话 | RDB/AOF（会话可重建，非必须长期保留） |
| MinIO 对象（病历文档/知识库） | 跨 bucket 版本化 + 异地复制 |
| 配置文件 / Secret | 配置中心快照 + 加密导出 |
| 审计日志 | 不可变归档，单独保留 ≥ 15 年 |
| 应用代码/镜像 | Git 仓库 + 私有镜像仓库 |

## 3. 备份频率

| 数据 | 频率 |
| --- | --- |
| 数据库全量 | 每日 1 次（业务低峰） |
| WAL 增量 | 实时归档 |
| 配置 | 每次变更后 |
| 审计日志 | 实时 |
| 知识库对象 | 每日增量 + 每周全量 |

## 4. 备份存储

- 本地 RAID + 异地/同城灾备站点；
- 备份加密存储；访问受限；离线副本防勒索。

## 5. 备份验证

- 每季度执行一次"恢复到隔离环境"演练，验证可用；
- 校验备份完整性（checksum / 恢复冒烟）。

## 6. 恢复流程

| 类型 | 步骤 |
| --- | --- |
| 完整恢复 | 停服 → 恢复最近全量 → 重放 WAL → 校验 → 启动 |
| 部分恢复 | 按表/对象定点恢复，避免全库覆盖 |
| 时间点恢复（PITR） | 利用 WAL 恢复到误操作前时刻 |

## 7. RTO / RPO 目标

| 目标 | 生产集群 |
| --- | --- |
| RTO（恢复时间） | ≤ 30 分钟 |
| RPO（数据丢失） | ≤ 5 分钟 |
| 审计日志 RPO | 0（实时双写） |

## 8. 灾难恢复演练

- 每半年一次实战切换演练（主备切换/异地拉起）；
- 演练后出具报告，更新预案与联系人。
