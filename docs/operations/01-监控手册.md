## 1. 监控指标体系

| 类别 | 关注点 | 示例指标 |
| --- | --- | --- |
| 系统指标 | 基础设施健康 | CPU、内存、磁盘、网络、句柄 |
| 应用指标 | 服务运行 | QPS、响应时间、错误率、并发数、队列长度 |
| 业务指标 | 临床可用性 | 危急值处理时效、处方审核时效、接口成功率 |
| 安全指标 | 合规与防护 | 异常登录、越权拦截、脱敏命中率、审计完整率 |

## 2. 监控工具配置

- **Prometheus**：抓取应用 `/metrics` 与 node-exporter、postgres-exporter、redis-exporter；
- **Grafana**：可视化面板，按角色（运维/临床/安全）分视图；
- **AlertManager**：告警路由与分级通知。

应用需暴露以下埋点（建议使用 `prom-client`）：

```text
agent_turns_total            # Agent 推理轮次
tool_call_total{tool,result} # 工具调用次数与结果
tool_duration_seconds        # 工具耗时直方图
cds_block_total              # CDS 拦截次数
adapter_upstream_seconds     # 外部接口耗时
```

## 3. 关键监控指标

| 指标 | 正常阈值 | 告警阈值 |
| --- | --- | --- |
| CPU 使用率 | < 60% | > 85% 持续 5min |
| 内存使用率 | < 70% | > 90% 持续 5min |
| 磁盘使用率 | < 70% | > 85% |
| 网络入/出 | 基线内 | 突增 3 倍 |
| API P95 响应时间 | < 500ms | > 1500ms |
| 错误率 | < 0.5% | > 2% |
| 并发会话数 | < 容量 70% | > 90% |
| LLM 端到端 | < 8s | > 20s |

## 4. 医疗场景特殊监控

| 指标 | 定义 | 目标 |
| --- | --- | --- |
| 危急值处理时效 | 从上报到医生确认的时长 | P95 < 10 分钟 |
| 处方审核时效 | 药师接单到审核完成 | P95 < 30 分钟 |
| HIS 接口可用性 | 健康检查成功率 | ≥ 99.9% |
| LIS/PACS 接口可用性 | 同上 | ≥ 99.5% |
| CDS 拦截漏报率 | 事后抽检 | 0（重大安全类） |
| 审计日志完整率 | 应记未记比例 | = 100% |

## 5. 监控面板设计

- **总览面板**：在线医生数、今日工具调用量、错误率、接口可用性。
- **性能面板**：P50/P95/P99 响应时间、队列积压、HPA 副本数。
- **临床面板**：待处理危急值、待审处方/医嘱、病历质控通过率。
- **安全面板**：越权拦截趋势、异常登录、密钥轮换状态、日志链完整性。

## 6. 数据采集与存储

- 指标：Prometheus 本地保留 15 天，长期经远端存储（Thanos/Mimir）保留 13 个月；
- 日志：Loki/ES 在线 30 天，归档对象存储 ≥ 1 年；审计日志合规留存 ≥ 15 年；
- 采样：高基数标签（如完整患者ID）禁止进入指标，统一脱敏。
