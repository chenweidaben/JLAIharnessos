# 告警手册

> 健澜科技数智医院智能体 · 告警分级与处置
> 版本 v1.0 ｜ 2026-09

## 1. 告警级别定义

| 级别 | 定义 | 响应要求 | 示例 |
| --- | --- | --- | --- |
| P0 紧急 | 系统不可用/重大数据安全事件 | 5 分钟内响应，电话呼叫 | 全站宕机、数据库主库宕机、审计链断裂 |
| P1 严重 | 核心功能受损 | 15 分钟内响应 | HIS 接口全断、危急值未推送 |
| P2 一般 | 局部异常、有降级 | 1 小时内响应 | 单工具错误率升高、缓存命中率下降 |
| P3 提示 | 趋势性/容量预警 | 工作时间处理 | 磁盘将满、证书 30 天到期 |

## 2. 告警规则配置

| 规则 | 阈值 | 持续时间 | 频率 |
| --- | --- | --- | --- |
| 服务健康检查失败 | 连续失败 3 次 | 1min | 每 5min 收敛 |
| CPU/内存 | > 85% | 5min | 每 10min |
| 错误率 | > 2% | 3min | 每 5min |
| 危急值积压 | 未处理 > 3 条 | 实时 | 每 2min 升级 |
| HIS 接口失败率 | > 5% | 2min | 每 3min |

## 3. 告警通知渠道

| 级别 | 渠道 |
| --- | --- |
| P0 | 电话 + 短信 + 企业微信/钉钉值班群 |
| P1 | 短信 + 企业微信/钉钉 |
| P2 | 企业微信/钉钉群 |
| P3 | 邮件 + 工单 |

## 4. 告警升级机制

- P0：5 分钟未确认 → 升级到二线；15 分钟未处置 → 升级到值班主管 + 厂商；
- P1：30 分钟未确认 → 升级为 P0；
- 升级路径：值班工程师 → 技术主管 → 信息科负责人 → 院方领导（重大事件）。

## 5. 告警处理流程

```
接收告警 → 确认认领 → 初步定位（看面板/日志/traceId）
→ 按预案处置 → 验证恢复 → 关闭并复盘
```

## 6. 告警抑制与收敛

- 同一根因的多级告警合并（如主库宕机自动抑制从库连接失败告警）；
- 维护窗口内按 silence 规则静默计划内变更；
- 每日统计告警量，消除噪声规则，避免告警疲劳。

## 7. 常见告警处理指南

| 告警 | 立即动作 |
| --- | --- |
| 健康检查失败 | 查 Pod/进程状态、最近发布、资源水位；必要时回滚 |
| HIS 接口超时 | 查集成总线、白名单、厂商状态；切只读降级 |
| 危急值积压 | 检查 LIS→本系统推送链路，人工补推 |
| 磁盘将满 | 清理日志/临时文件，扩容，归档旧数据 |
| 证书到期 | 续签并滚动更新 Ingress Secret |
