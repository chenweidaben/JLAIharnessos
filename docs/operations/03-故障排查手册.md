# 故障排查手册

> 健澜科技数智医院智能体 · 故障定位与应急恢复
> 版本 v1.0 ｜ 2026-09

## 1. 系统故障分类

| 类别 | 典型场景 |
| --- | --- |
| 硬件 | 主机宕机、磁盘损坏、网络设备故障 |
| 网络 | 内网不通、防火墙拦截、专线中断 |
| 数据库 | 连接失败、慢查询、主从延迟、磁盘满 |
| 应用 | 进程崩溃、OOM、死锁、版本缺陷 |
| 外部接口 | HIS/EMR/LIS/PACS 超时或不可用 |

## 2. 故障排查通用流程

```
信息收集（现象/时间/影响面/traceId）
  → 问题定位（分层：接入/应用/数据/外部）
  → 根因分析（日志/指标/变更）
  → 解决方案（回滚/扩容/切换/降级）
  → 验证恢复（健康检查+业务抽查）
  → 复盘归档
```

## 3. 常见故障排查

### 3.1 应用无法启动

- 现象：进程退出、systemd 失败。
- 排查：`journalctl -u jianlan-agent -f`；核对 `.env` 必需项；`bun run typecheck`；端口占用 `ss -lntp`。

### 3.2 响应缓慢

- 看 P95 面板定位慢环节；
- LLM 慢：查模型网关、并发、超时配置；
- DB 慢：`pg_stat_activity`、慢查询日志、是否缺索引。

### 3.3 内存泄漏

- 进程 RSS 持续上涨不回落；
- 抓取堆快照（--heapsnapshot）；检查缓存/向量库连接未释放；重启止血后排查。

### 3.4 数据库连接失败

- 核对 `DATABASE_URL`、密码、pg_hba；
- `pg_isready`；连接池是否耗尽（max_connections）。

### 3.5 HIS 接口超时

- 集成总线 `healthCheck()`；白名单与防火墙；厂商侧状态；必要时切 Mock/只读降级。

### 3.6 LIS 接口异常

- 检验结果未回传：查 ORU 消息通道；危急值推送队列积压。

### 3.7 PACS 影像无法调阅

- 检查 DICOMweb（QIDO/WADO）网关权限与网络；studyId 是否正确；PACS 侧是否归档。

### 3.8 危急值未推送

- 查 LIS→本系统事件链路与 AlertManager；人工核查并补推，记录事故。

### 3.9 处方审核失败

- 合理用药检查（CDS）是否误拦截；药师账号处方审核权限；药品字典同步。

### 3.10 用户无法登录

- 认证服务/会话服务状态；账号锁定、密码策略；CA 证书过期。

## 4. 日志分析指南

- 按 `traceId` 串联一次请求全链路；
- 结构化日志关键字段：`level / toolName / userId / patientId(脱敏) / error.code`；
- 常用：`grep` 错误码、按 traceId 聚合、按时间窗统计。

## 5. 性能分析工具

- Bun `--inspect` 调试；Chrome DevTools 性能面板；
- PostgreSQL `EXPLAIN ANALYZE`；`pg_stat_statements`；
- 链路追踪（如接入 OpenTelemetry）按 span 定位耗时。

## 6. 应急恢复预案

| 场景 | 预案 |
| --- | --- |
| 应用版本缺陷 | 立即回滚上一镜像版本 |
| 主库故障 | 提升从库为主（自动/手动） |
| 外部系统不可用 | 切只读/Mock 降级，保障病历浏览与 CDS |
| 数据误删 | 按时间点恢复（PITR），见备份恢复手册 |

> 所有 P0/P1 故障须在 3 个工作日内输出复盘报告。
