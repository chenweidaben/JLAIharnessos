# 生产上线验收清单（Go-Live Checklist）

> 适用：健澜科技杠OS 生产环境首次上线与重大版本发布。
> 规则：所有 **P0（阻断项）** 必须全部通过并签署，方可切流；P1 项允许带明确整改期限上线，
> 但需在发布单中记录负责人与截止时间。建议在上线前 T-7 天冻结代码，T-1 天完成彩排。

## 一、构建与制品（P0）

- [ ] 代码来自受保护 `main` 分支的发布 Tag，`bun run typecheck` 零错误
- [ ] 后端 `bun test`、前端 `cd web && npx vitest run` 全绿，覆盖率不低于基线（后端 ≥ 85%）
- [ ] `bun run lint` 无 error；`npm run build`（前端）与后端构建成功
- [ ] 镜像/制品使用不可变 Tag（版本号 + digest），禁止 `latest` 上生产
- [ ] 制品经过安全扫描：`bun audit`/依赖扫描无高危未处置，gitleaks 无密钥泄露
- [ ] 在与生产同构的**预发环境**完成部署并回归通过

## 二、配置与密钥（P0）

- [ ] 所有默认口令已更换（PostgreSQL、Redis、Grafana、消息队列等）
- [ ] `JWT_SECRET`、`ENCRYPTION_MASTER_KEY` 为强随机值，经密钥管理系统/KMS 注入，**不落盘、不入仓库**
- [ ] `.env` 权限收紧（仅运行账号可读），生产配置与开发/测试隔离
- [ ] 日志级别设为 `info` 或 `warn`，关闭演示数据/演示告警（`NODE_ENV=production`）
- [ ] 资源配额（CPU/内存/副本数/连接池/限流阈值）按容量规划设置
- [ ] 明确功能开关：CDS 拦截、脱敏、人工确认、双复核、MFA 强制策略

## 三、安全与合规（P0）

- [ ] 全链路 HTTPS/TLS（含内网东西向按需 mTLS），证书有效期与自动续期已验证
- [ ] 安全响应头（CSP、HSTS、X-Frame-Options 等）生效；CSRF/限流/WAF 策略就位
- [ ] 管理员与高风险角色**强制 MFA**（TOTP），二次验证在敏感操作生效
- [ ] RBAC/ABAC 权限矩阵经业务确认，最小权限；越权用例（水平/垂直）测试通过
- [ ] 数据脱敏、分级分类、导出审批、审计日志（哈希链）开启并抽检可追溯
- [ ] Prompt 注入、SQL 注入、XSS、命令注入、越权、文件上传等安全用例通过
- [ ] `/metrics`、`/ready`、管理端口不对公网暴露；`/metrics` 配置 token 或网络隔离
- [ ] 等保三级相关控制项完成自评/测评（按部署方要求），留存证据
- [ ] 个人信息/数据出境合规评估完成，数据不出院/不出境策略落实

## 四、数据与知识库（P0）

- [ ] PostgreSQL 扩展（pgvector 等）、Schema、索引、种子数据初始化并校验
- [ ] 数据库账号最小权限分离（应用账号/迁移账号/只读报表账号）
- [ ] 连接池、慢查询、归档策略配置；备份与 WAL 归档开启
- [ ] **恢复演练通过**：全量 + WAL/PITR 在隔离环境成功恢复（见《容灾演练手册》）
- [ ] Redis 持久化/淘汰策略、密码、TLS（如需要）确认
- [ ] 医学知识库来源与许可证合规（见 DATA_LICENSES.md），受限数据未非法打包
- [ ] CDS 规则、药品库、危急值阈值经临床/药学专家审核签认

## 五、系统集成（P0/P1）

- [ ] HIS/EMR/LIS/PACS 适配器在真实或仿真联调环境连通（P0 为本期必接系统）
- [ ] HL7/FHIR/DICOM 消息解析与字段映射经真实样本验证，编码映射表签认
- [ ] 适配器重试、熔断、超时、降级、死信队列生效，故障注入测试通过
- [ ] 危急值/告警端到端可达（BFF→WebSocket/前端→责任人）并完成一次真实闭环演练
- [ ] 时钟同步（NTP）、字符集、时区（Asia/Shanghai）一致
- [ ] 未接入系统在界面与文档中明确标注，避免误用（P1）

## 六、可观测与运维（P0）

- [ ] Prometheus 抓取 BFF/组件目标全部 UP，无持续 pending/firing 误报
- [ ] Grafana「平台总览」大盘数据正常，数据源/大盘自动装配生效
- [ ] 告警规则触发验证（错误率、P95、智能体/工具失败率、目标宕机、危急值激增）
- [ ] 告警通知渠道（短信/电话/IM/邮件）与值班轮转、升级矩阵确认
- [ ] 链路追踪（Jaeger）、集中日志（采集/留存周期/脱敏）可用
- [ ] 健康探针 `/health`（存活）、`/ready`（就绪）接入编排系统，滚动发布验证通过
- [ ] 优雅停机（SIGTERM 摘流、在途请求收尾、连接排空）验证通过
- [ ] 运维手册、故障排查 Runbook、值班/ escalation 路径齐备并培训

## 七、性能与容量（P0/P1）

- [ ] k6 冒烟通过；常规负载下错误率 < 1%、P95 < 500ms、P99 < 1s（按实际 SLO）
- [ ] 压力测试确定拐点与限流阈值，过载时表现为限流/降级而非雪崩（P0）
- [ ] 关键业务场景（门诊高峰、批量质控、危急值并发）容量满足预期并留 ≥ 30% 余量
- [ ] 数据库/缓存/消息队列容量与磁盘水位、扩容方案确认（P1）

## 八、临床安全与业务验证（P0）

- [ ] 十大刚需智能体在真实/仿真数据下完成验收，输出经临床专家评估
- [ ] 高风险动作（处方、医嘱、病历归档）人工确认/双复核流程全部走通
- [ ] AI 输出明确标注"辅助建议"，免责声明展示；错误/幻觉处置与人工兜底流程明确
- [ ] 语音录入剂量/频次"只提示不改数字"等安全约束验证
- [ ] 完成至少一次端到端业务彩排：门诊问诊、住院查房、危急值处置、处方审核
- [ ] 一线医护培训、操作手册、问题反馈渠道就位

## 九、回滚与应急（P0）

- [ ] 数据库变更均有回滚/前滚方案，破坏性变更已备份并评审
- [ ] 蓝绿/金丝雀或回滚流程验证，明确回滚决策人与最长决策时间
- [ ] 功能降级开关清单（可一键关闭 CDS 拦截/AI 生成/外部调用）验证有效
- [ ] 上线窗口、沟通话术、业务高峰避让、现场值守安排确认
- [ ] 应急预案与联系人（厂商 DBA/网络/安全/临床）到位

## 十、发布后观察（T+0 / T+1 / T+7）

- [ ] T+0：全程值守，盯盘错误率/时延/资源/告警，关键科室首小时专人陪护
- [ ] T+1：复盘首日问题，核对审计日志、告警、备份成功记录
- [ ] T+7：输出上线观察报告（稳定性、性能、临床反馈、问题清单），转入常态运维
