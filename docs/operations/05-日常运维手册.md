# 日常运维手册

> 健澜科技数智医院智能体 · 例行检查与变更管理
> 版本 v1.0 ｜ 2026-09

## 1. 每日检查清单

- [ ] 查看 P0/P1 告警是否清零
- [ ] 应用实例与健康检查状态正常
- [ ] PostgreSQL 主从延迟在阈值内、备份任务成功
- [ ] Redis、MinIO 可用
- [ ] 危急值/待审处方无异常积压
- [ ] HIS/EMR/LIS/PACS 接口可用性正常

## 2. 每周检查清单

- [ ] 错误率与 P95 响应时间趋势复盘
- [ ] 磁盘增长与容量预测
- [ ] 备份恢复抽验
- [ ] 安全告警（异常登录/越权）周报

## 3. 每月检查清单

- [ ] 证书/密钥到期巡检（≥30 天提醒）
- [ ] 资源使用与 HPA 上下限复核
- [ ] 日志/指标保留与归档合规检查
- [ ] 知识库版本与规则更新评审

## 4. 季度检查清单

- [ ] 备份恢复实战演练
- [ ] 安全基线与补丁升级
- [ ] 容量规划复盘与扩容决策
- [ ] 应急预案与联系人更新

## 5. 年度检查清单

- [ ] 等保三级年度测评配合
- [ ] 容灾切换全链路演练
- [ ] 架构与容量年度评审
- [ ] 许可证/供应商合同续签

## 6. 系统巡检流程

```
登录监控面板 → 按日/周清单逐项核对 → 记录结果 → 异常转工单 → 闭环
```

## 7. 性能调优指南

- 慢 SQL：`pg_stat_statements` 定位 → 加索引/改写；
- 向量检索：调整 `topK`、召回阈值、embedding 维度；
- LLM：调整上下文压缩策略、缓存高频问答；
- 应用：调整连接池、HPA、并发上限。

## 8. 容量规划

- 按月统计在线医生数、会话数、工具调用量、知识库增量；
- 提前 1 个季度规划 CPU/内存/磁盘/向量库扩容；
- 新院区/新科室上线前做容量评估。

## 9. 版本升级流程

```
需求/补丁评审 → 测试环境验证 → 灰度（1 副本）→ 观察 → 全量 → 回滚预案就绪
```

## 10. 配置变更流程

- 任何配置/规则/字典变更走审批；
- 变更前备份；变更后健康检查 + 业务抽查；
- 高风险变更安排在业务低峰并通知临床科室。
