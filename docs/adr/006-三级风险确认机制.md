# ADR-006 三级风险确认机制

- 状态：已接受 ｜ 日期：2026-05 ｜ 决策者：安全合规团队

## 背景

AI 自动开医嘱/处方风险极高，必须防止模型误操作直接影响患者。

## 决策

按 `riskLevel` 实施三级确认：low 只读直接执行；medium 写操作单次用户确认；high 高危写操作双重确认 + 执业医师/处方权校验 + CA 签名。`ToolRiskManager` 在执行前决策级别，fail-closed。

## 后果

- 正面：高危操作人机协同，符合医疗责任要求。
- 负面：操作链路变长，需优化交互减少打扰。
- 折中：低风险只读零确认，仅对高危增加摩擦。
