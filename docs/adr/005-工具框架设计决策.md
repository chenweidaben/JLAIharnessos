# ADR-005 工具框架设计决策

- 状态：已接受 ｜ 日期：2026-05 ｜ 决策者：医疗工具团队

## 背景

医疗工具既需要统一的执行契约，又需要差异化的安全语义（只读/写/高危）。

## 决策

定义 `MedicalToolDefinition` 统一契约（name/description/category/riskLevel/inputSchema/outputSchema/execute），通过 `buildMedicalTool` 工厂自动填充 fail-closed 安全默认值（权限校验、审计、确认、脱敏）。工具经 `MedicalToolRegistry` 注册、`ToolExecutor` 受控执行。

## 后果

- 正面：36 个工具实现一致，安全逻辑一处维护；新增工具成本低。
- 负面：框架抽象需团队遵守约定。
- 折中：保留 `validateMedicalInput/checkMedicalPermissions` 钩子支持工具级定制。
