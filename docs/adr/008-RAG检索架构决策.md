# ADR-008 RAG 检索架构决策

- 状态：已接受 ｜ 日期：2026-06 ｜ 决策者：知识库团队

## 背景

CDS 与问答需要循证依据，纯参数化模型易幻觉。需要可溯源的知识检索。

## 决策

采用"查询理解 → 向量召回（pgvector）→ 重排（Reranker）→ 上下文拼装"流水线。知识经 DocumentParser/TextSplitter 切片、EmbeddingService 向量化入库，结果带引用来源。

## 后果

- 正面：回答可溯源，缓解幻觉；知识可独立更新。
- 负面：依赖知识库质量与向量模型一致性。
- 折中：检索结果标注置信度与引用，低置信度不直接落结论。
