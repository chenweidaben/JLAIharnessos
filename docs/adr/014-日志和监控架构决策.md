# ADR-014 日志和监控架构决策

- 状态：已接受 ｜ 日期：2026-07 ｜ 决策者：运维团队

## 背景

临床系统要求可观测与可追溯，故障需快速定位。

## 决策

统一 traceId 贯穿全链路；应用结构化日志经 Prometheus/Grafana 监控指标、Loki/ELK 日志聚合；审计日志独立通道、哈希链完整校验、长期留存。指标禁止高基数标签（如完整患者ID）。

## 后果

- 正面：故障可按 traceId 定位，审计合规留存。
- 负面：需采集与存储成本。
- 折中：在线热数据短期，冷数据归档降本。
