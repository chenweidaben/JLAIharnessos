# ADR-012 系统集成架构决策

- 状态：已接受 ｜ 日期：2026-07 ｜ 决策者：集成团队

## 背景

医院 HIS/EMR/LIS/PACS 厂商众多、协议各异（HL7 v2、FHIR、私有接口）。

## 决策

采用适配器模式（BaseAdapter + AdapterRegistry）封装多厂商实现，经 IntegrationBus 做协议转换、FieldMapper 做字段映射、熔断与重试。协议层独立为 HL7/FHIR/DICOM 解析模块。

## 后果

- 正面：新厂商接入只需新增适配器；业务与协议解耦。
- 负面：集成测试面广，依赖厂商配合。
- 折中：提供 Mock 适配器支持开发/测试，生产配置化切换。
