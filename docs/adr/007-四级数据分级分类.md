# ADR-007 四级数据分级分类

- 状态：已接受 ｜ 日期：2026-05 ｜ 决策者：安全合规团队

## 背景

医疗数据敏感度差异大，需按级别决定加密、脱敏与访问策略，满足数据安全法。

## 决策

将数据分为四级：公开 / 内部 / 敏感（含 PHI）/ 极敏感（诊断、处方、身份标识）。`DataClassifier` 自动分级，`DesensitizationEngine` 对展示层脱敏（姓名/身份证/电话/地址），`EncryptionService` 对敏感/极敏感字段加密存储与传输。

## 后果

- 正面：精细化合规，最小化暴露；脱敏不影响流程。
- 负面：分级规则需随业务维护。
- 折中：输出默认脱敏，经权限提升才见明文。
