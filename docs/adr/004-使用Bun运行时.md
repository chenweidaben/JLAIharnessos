# ADR-004 使用 Bun 运行时

- 状态：已接受 ｜ 日期：2026-04 ｜ 决策者：核心引擎团队

## 背景

Agent 应用对启动速度、TS 原生支持与工具链一体化要求高。Node 生态启动慢、需额外编译。

## 决策

选用 Bun ≥ 1.3.0（packageManager: bun@1.3.11）作为运行时与包管理，`bun build` 产出，`bun test` 测试；保留 Node ≥ 18 作为部分工具的兼容底座。

## 后果

- 正面：启动快、TS 原生、单工具链，开发体验好。
- 负面：部分 npm 包兼容性需验证；生态较新。
- 折中：对不兼容依赖通过兼容层隔离，关键路径回归测试兜底。
