# ADR-009 CDS 规则引擎设计决策

- 状态：已接受 ｜ 日期：2026-06 ｜ 决策者：知识库团队

## 背景

药物相互作用、危急值、禁忌等需确定性规则，不能依赖大模型概率输出。

## 决策

独立规则引擎（CDSEngine + RuleEvaluator + ActionExecutor），按诊断/检验/药品三类规则集评估，命中后输出 info/warning/block 三级动作，block 级直接拦截高危操作。规则与模型解耦、可热更新。

## 后果

- 正面：安全拦截确定性、可解释、可审计。
- 负面：规则维护成本，需临床专家参与。
- 折中：与生成式建议互补——规则负责红线，模型负责建议。
