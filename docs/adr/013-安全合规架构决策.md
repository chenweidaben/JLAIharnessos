# ADR-013 安全合规架构决策

- 状态：已接受 ｜ 日期：2026-07 ｜ 决策者：安全合规团队

## 背景

医疗系统须满足等保三级、个人信息保护法与医疗数据不出院要求。

## 决策

纵深防御：传输/存储加密（AES-GCM + 密钥轮换）、RBAC+ABAC 权限、四级数据分级与脱敏、不可篡改审计日志（哈希链）、Prompt 注入防护（PromptInjectionGuard）与输入校验。fail-closed：安全校验失败默认拒绝。

## 后果

- 正面：合规可审计，数据最小暴露。
- 负面：开发与运维需遵守安全默认，性能略有开销。
- 折中：按数据分级施加安全成本，非敏感数据轻量处理。
