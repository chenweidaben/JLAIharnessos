# ADR-010 子代理系统设计决策

- 状态：已接受 ｜ 日期：2026-06 ｜ 决策者：核心引擎团队

## 背景

不同科室诊疗范式差异大，单一大提示词难以兼顾专科深度。

## 决策

设计 8 类科室子代理（内科、外科、儿科、妇产科、急诊、ICU、手术室、医技科），由 BuddyManager/MedicalBuddy 管理，按科室注入专科系统提示与技能；通过 SuperScheduler/AgentRegistry 进行编排与转介。

## 后果

- 正面：专科化提升场景准确度；可独立迭代。
- 负面：维护多套提示与技能成本上升。
- 折中：共享基础工具与安全层，仅差异化专科知识。
