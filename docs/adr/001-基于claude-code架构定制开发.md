# ADR-001 基于 claude-code 架构定制开发

- 状态：已接受 ｜ 日期：2026-04 ｜ 决策者：核心架构组

## 背景

从零构建医疗 Agent 引擎成本高、周期长。市场上 claude-code 2.1.88 已具备成熟的 Agent 循环、工具框架、会话与上下文管理，且源代码（source map 还原版）可获得。

## 决策

基于 claude-code 2.1.88 架构进行医疗化深度定制：复用核心引擎（复用率约 79%）、Ink UI 框架与键位/命令体系，替换工具集、技能库与安全体系为医疗领域实现。

## 后果

- 正面：大幅缩短研发周期，直接继承成熟 Agent 工程能力。
- 负面：受上游架构约束，需持续跟踪上游变更并维护差异。
- 折中：医疗专用模块（medical-tools/knowledge/security/integration）独立于复用层，降低耦合。
