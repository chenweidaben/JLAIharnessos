# ADR-003 使用 Ink 终端 UI 框架

- 状态：已接受 ｜ 日期：2026-04 ｜ 决策者：UI/交互团队

## 背景

医生工作站环境多样，需要轻量、可远程 SSH/终端部署的交互形态，避免重前端工程的部署负担。

## 决策

采用 React 19 + Ink 6.8 终端渲染框架，将医疗场景界面（聊天、工具确认、危急值告警、键位）渲染为 TUI。

## 后果

- 正面：部署轻、复用 claude-code 设计系统、适合院内终端。
- 负面：图形/影像富交互能力弱，复杂阅片仍跳转 PACS。
- 折中：保留服务端 API（Hono/Express），后续可叠加 Web 前端复用同一后端。
