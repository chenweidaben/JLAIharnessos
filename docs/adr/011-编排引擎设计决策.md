# ADR-011 编排引擎设计决策

- 状态：已接受 ｜ 日期：2026-06 ｜ 决策者：核心引擎团队

## 背景

多智能体协作（会诊、转介、并行任务）需要统一调度，避免混乱调用。

## 决策

引入编排层：IntentClassifier 识别意图，SuperScheduler 统一调度主代理与子代理，CollaborationEngine/ConsultationManager 处理多学科会诊；后台任务由 BackgroundTaskManager/TaskQueue 异步执行，避免阻塞主循环。

## 后果

- 正面：复杂多角色协作可控，长任务异步化。
- 负面：编排复杂度与调试难度上升。
- 折中：默认单代理直答，仅在需要时升级编排。
