# ADR-015 部署架构决策

- 状态：已接受 ｜ 日期：2026-07 ｜ 决策者：运维团队

## 背景

需同时满足开发测试简便、生产高可用与医疗数据不出院。

## 决策

提供三种部署模式：单机（开发/测试）、集群（生产，应用无状态横向扩展 + PG 主从 + Redis + MinIO 分布式）、混合（数据院内、推理可加密出网）。容器化（Docker/K8s/Helm）交付，云原生 HPA + 服务网格 + 可观测。

## 后果

- 正面：一套代码多环境，生产高可用且合规。
- 负面：运维复杂度上升，需专业 SRE。
- 折中：单机模式降低起步门槛，随规模平滑演进到集群。
