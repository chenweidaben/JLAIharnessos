# ADR-002 使用 TypeScript 严格模式

- 状态：已接受 ｜ 日期：2026-04 ｜ 决策者：核心架构组

## 背景

医疗系统对正确性要求极高，动态语言运行时错误风险大。需要在编译期最大化类型安全。

## 决策

全项目使用 TypeScript 6.0+，开启严格模式（`strict`），工具入参/出参使用 Zod Schema 双端校验（编译期类型 + 运行时校验）。

## 后果

- 正面：类型错误在编译期暴露，医疗数据结构契约清晰；Zod 提供运行时防护。
- 负面：初期开发成本略高，样板代码增多。
- 折中：通过 `buildMedicalTool` 工厂与类型推导减少重复。
