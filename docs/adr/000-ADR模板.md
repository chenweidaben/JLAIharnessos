# ADR 模板

> 架构决策记录（Architecture Decision Record）标准格式
> 健澜科技数智医院智能体

每个 ADR 采用统一结构，一旦"已接受"即不可修改，新决策通过新增 ADR 修正。

## 标题

[一句话概括决策内容]

- 状态：`提案 / 已接受 / 已废弃 / 被 ADR-XXX 取代`
- 日期：YYYY-MM-DD
- 决策者：核心架构组

## 背景（Context）

描述面临的问题、约束与可选方案，说明为什么需要做这个决策。

## 决策（Decision）

明确做出的选择，以及关键技术取舍。

## 后果（Consequences）

- 正面：带来的收益；
- 负面：引入的成本、限制与风险；
- 折中：未来需要关注的债务。

## 参考（References）

相关文档、讨论、原型、竞品对比等。
