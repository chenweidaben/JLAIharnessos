## 使用说明

1. 本清单为**可打印 Checklist**，测评机构可逐项打勾。
2. 每项字段：**编号 / 要求描述 / 依据条款 / 责任团队 / 验证方式 / 当前状态**。
3. 当前状态四档：⬜ 未开始 / 🟦 计划中 / 🟨 进行中 / ✅ 已完成。
4. 本清单基线日期为 2026-10-19（M1 起点），所有项默认 ⬜ 未开始。
5. 责任团队缩写：
   - **ARCH**：首席架构师 / 架构组
   - **JAVA**：Java 核心组
   - **PYAI**：Python AI 组
   - **OPS**：运维 / SRE
   - **SEC**：安全 / 合规组（合规官）
   - **DOM**：医疗 Domain Expert
   - **DELIV**：交付 / 售后
   - **PMO**：项目管理办公室
   - **RA**：法规事务（医疗器械方向）

## 11. 不符合项管理流程

测评机构或内部自查发现不符合项后，按以下流程闭环：

1. **录入**：24 小时内录入本清单对应项，状态改为 🟨 进行中；同时在 `合规档案/不符合项/` 下建立整改文件夹。
2. **定级**：按影响范围分三级——
   - 一级（致命）：违反法律红线（PHI 出境、病历可篡改、未国密即测评），72 小时内启动整改，不得上线；
   - 二级（重要）：测评不符合项但不违反法律，2 周内完成整改；
   - 三级（一般）：文档不规范、配置不完整，1 个月内完成整改。
3. **整改**：责任人提交整改计划（动作、工期、资源），合规官审批后执行。
4. **复测**：整改完成后，责任人提交证据，合规官组织复测；复测通过，状态改为 ✅。
5. **复盘**：一级不符合项整改完成后，1 周内召开复盘会，更新架构宪法或 checklist，防止同类问题复发。

**不符合项的升级机制**：
- 同一一级不符合项 3 个月内重复出现 2 次，升级为 CTO 级问题；
- 同一模块不符合项率 >20%，该模块暂停切流，直到整改完成；
- 等保测评前 1 个月，若 checklist 完成度 <80%，测评启动推迟。
