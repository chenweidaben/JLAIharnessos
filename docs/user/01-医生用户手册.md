## 1. 系统登录与身份认证

使用工号/CA 证书登录。系统按角色（doctor）授予 `patient:read`、`emr:write`、`order:create`、`prescription:create` 等权限。所有操作记录审计日志。

## 2. 门诊问诊流程

```
选择患者(query_patient / get_patient_detail)
  → AI 辅助问诊(get_patient_history + 对话)
  → 病历生成(generate_medical_record，医生确认)
  → 医嘱开具(create_order)
  → 处方开具(create_prescription，药师审核)
```

- 高风险操作（医嘱/处方）会弹出确认，需二次确认并校验处方权。

## 3. 住院查房流程

```
查看患者列表 → 进入患者查房
  → AI 查房建议(CDS + 历史)
  → 书写查房记录(generate_medical_record)
  → 调整医嘱(create_order / cancel_order)
```

## 4. 急诊分诊流程

- 急诊患者标记 `isEmergency`，优先级"急/即刻"；
- 危急值实时推送（critical_value_alert），需在 10 分钟内确认。

## 5. 临床决策支持使用

- **诊断建议**（diagnosis_suggestion）：输入症状，获得鉴别诊断列表（仅供参考，需医生确认）；
- **治疗方案建议**（treatment_plan_suggestion）：基于诊断推荐用药路径；
- **药物相互作用检查**（drug_interaction_check）；
- **危急值提醒**（critical_value_alert）。

> CDS 为辅助决策，最终诊疗责任由医生承担。

## 6. 知识库查询

直接用自然语言提问，系统基于院内指南/药品库/制度进行 RAG 检索并给出引用来源。

## 7. 病历书写辅助

AI 生成病历草稿后，**必须**由医生核对、修改、确认后方可落库；系统保留修改痕迹。

## 8. 医嘱和处方开具

- 医嘱：`create_order`，自动 CDS 安全检查（过敏/相互作用/禁忌）；
- 处方：`create_prescription`，按普通/特殊/麻醉分级；药品处方需药师审核后生效；
- 作废：`cancel_order`，需填写原因。

## 9. 检验检查申请和结果查看

- 申请：`order_lab_test` / `order_imaging_exam`；
- 结果：`get_lab_result` / `get_image_report`，异常项与危急值醒目提示。

## 10. 影像调阅

`view_dicom` 拉取影像元数据与序列，跳转 PACS 阅片；本系统不直接处理像素。

## 11. 会诊发起和参与

- 发起多学科会诊，由协作引擎（CollaborationEngine）转介相关科室子代理；
- 参与会诊时在会话中查看各方建议与患者上下文。

## 12. 常见问题

| 问题 | 解决 |
| --- | --- |
| 开医嘱被拦截 | 查看 CDS 提示（过敏/禁忌），调整用药 |
| 处方被退回 | 联系药师查看退回原因 |
| 患者查不到 | 核对 patientId/mpi，或联系信息科 |
| 影像打不开 | 检查网络/PACS 状态，重试 |
