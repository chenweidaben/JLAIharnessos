# 药师用户手册

> 健澜科技数智医院智能体 · 药师角色使用指南
> 版本 v1.0 ｜ 2026-09

## 1. 处方审核流程

```
接收待审处方(prescription_audit)
  → 查看患者诊断与用药
  → 合理用药检查(CDS)
  → 通过 / 退回修改(填写审核意见)
```

- 仅药师角色可执行 `prescription:audit`；药品医嘱/处方自动流转药师审核队列。

## 2. 合理用药检查

系统自动提示药物相互作用、禁忌、过敏、剂量异常；药师在此基础上复核并给出结论。

## 3. 药品信息查询

`get_drug_info` / `getDrugInformation` 查询药品适应症、用法用量、相互作用、贮存。

## 4. 用药指导

对特殊人群（老人、儿童、肝肾功能不全）给出剂量与用药教育建议，供医生与患者参考。

## 5. 药品库存管理

配合 HIS 库存：核对处方与库存，缺药时退回并建议替代方案。

## 6. 常见问题

| 问题 | 解决 |
| --- | --- |
| 处方无审核权限 | 确认药师角色与 `prescription:audit` 权限 |
| 相互作用提示不准 | 反馈管理员调整药品规则 |
| 退回后医生看不到 | 确认已填写审核意见并提交 |
