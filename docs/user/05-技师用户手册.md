# 技师用户手册

> 健澜科技数智医院智能体 · 检验/影像技师使用指南
> 版本 v1.0 ｜ 2026-09

## 1. 检验检查申请接收

查看医生下传的检验（LIS）/影像（PACS）申请单，确认患者、项目与加急标识。

## 2. 标本管理

- 核申请单与标本条码一致；
- 记录接收、拒收、复检状态；不合格标本注明原因并退回。

## 3. 检验检查执行

按 SOP 执行检验/检查，过程数据回传 LIS/PACS。

## 4. 结果录入和审核

- 录入/确认结果；异常值与参考区间对照；
- 结果需复核后发布，医生侧方可查看。

## 5. 危急值上报

发现危急值立即按流程上报（`critical_value_alert` 联动），记录上报时间与接收人。

## 6. 设备管理

登记设备状态、校准与质控记录；设备故障时及时挂停对应申请通道。

## 7. 常见问题

| 问题 | 解决 |
| --- | --- |
| 收不到申请 | 检查 LIS/PACS 接口与队列 |
| 标本拒收 | 注明原因退回医生，重新采样 |
| 结果无法发布 | 核对是否已复核、LIS 是否正常 |
