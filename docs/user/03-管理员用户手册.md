# 管理员用户手册

> 健澜科技数智医院智能体 · 系统管理员使用指南
> 版本 v1.0 ｜ 2026-09

## 1. 系统管理

- **用户管理**：新增/停用账号、重置密码；
- **角色管理**：医生/护士/药师/技师/管理员角色分配；
- **权限管理**：基于 RBAC+ABAC 配置权限点（`PermissionMatrix`）。

## 2. 科室管理

维护科室字典、科室与医生归属、值班表。

## 3. 字典管理

维护诊断字典、药品字典（`drugCatalog`）、检查检验项目字典；变更需审核并记录版本。

## 4. 知识库管理

- 知识入库（`KnowledgeBaseManager.ingest`）：上传指南/制度/药品说明书；
- 更新与版本管理：支持回滚到历史版本；
- 监控入库成功率与切片质量。

## 5. CDS 规则管理

- 维护诊断/检验/药品规则（ruleIndex）；
- 调整阈值（如危急值范围）；规则变更灰度发布。

## 6. 系统配置

- 适配器开关与目标 HIS/EMR/LIS/PACS；
- 超时、重试、确认策略；
- 配置变更走审批（见日常运维手册）。

## 7. 日志审计

- 查询审计日志（按用户/工具/时间）；
- 校验日志链完整性（LogIntegrity.verify）；
- 导出合规审计包。

## 8. 报表统计

- 医疗质量指标（`medical_quality_indicators`）；
- 科室运营分析、DRG/DIP 分析。

## 9. 系统监控

查看监控面板（见监控手册），处理告警（见告警手册）。

## 10. 数据备份

执行与验证备份（见备份恢复手册），定期恢复演练。

## 11. 常见问题

| 问题 | 解决 |
| --- | --- |
| 新员工无权限 | 分配角色与权限点 |
| 知识库检索不准 | 检查入库切片与向量维度 |
| CDS 误报 | 调整规则阈值并灰度 |
