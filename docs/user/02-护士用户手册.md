# 护士用户手册

> 健澜科技数智医院智能体 · 护士角色使用指南
> 版本 v1.0 ｜ 2026-09

## 1. 系统登录

使用工号登录，系统按护士角色授予患者查询、医嘱查看与执行相关权限。

## 2. 患者信息查询

- 通过 `query_patient` / `get_patient_detail` 查询分管患者；
- 查看患者过敏史、当前用药，保障执行安全。

## 3. 医嘱执行和确认

- 查看医生已开立医嘱（`get_order_list`）；
- 按医嘱逐项执行并确认执行时间与执行人；
- 发现医嘱疑问时联系开单医生，不擅自执行有疑问医嘱。

## 4. 生命体征录入

按班次录入体温、脉搏、呼吸、血压、血氧等；异常值自动提示。

## 5. 护理记录

书写入院护理评估、病程护理记录、交接班记录；系统提供模板与 AI 辅助。

## 6. 危急值接收和处理

- 收到危急值提醒（critical_value_alert）后立即通知医生；
- 记录接收与通知时间，跟踪处置闭环。

## 7. 药品管理

- 核对药品名称、剂量、用法与医嘱一致；
- 高警示药品双人核对；麻精药品按制度登记。

## 8. 交接班

在系统中完成电子交接班，未完成事项（待执行医嘱、待观察患者）自动带入下一班。

## 9. 常见问题

| 问题 | 解决 |
| --- | --- |
| 看不到患者 | 确认分管床位/科室与权限 |
| 医嘱无法执行 | 状态是否已停止/作废，联系医生 |
| 危急值未提醒 | 检查网络，联系信息科 |
