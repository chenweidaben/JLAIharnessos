# 开发环境搭建

> 版本：v1.0 · 日期：2026-09-16

## 1. 前置依赖

| 软件 | 版本 | 说明 |
| --- | --- | --- |
| Bun | >= 1.3.0 | 主运行时 |
| Node.js | >= 18 | 部分 npm 工具依赖 |
| Git | >= 2.40 | 推荐开启 LF 自动转换 |
| VS Code | 最新稳定版 | 推荐插件见下文 |

## 2. 一键启动

```bash
git clone https://git.jianlan.tech/medical/jianlan-medical-agent.git
cd jianlan-medical-agent
bun install
cp .env.example .env.development
bun run dev
```

## 3. 编辑器配置

推荐 VS Code 插件：

- **ESLint**（自动按 `eslint.config.js` 检查）
- **Prettier - Code formatter**（设为默认格式化器）
- **Tailwind CSS IntelliSense**（如需 UI 主题扩展）
- **EditorConfig**（自动读取 `.editorconfig`）

推荐工作区设置（`.vscode/settings.json`）：

```json
{
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.formatOnSave": true,
  "editor.codeActionsOnSave": {
    "source.fixAll.eslint": "explicit"
  },
  "files.eol": "\n"
}
```

## 4. 环境变量

复制 `.env.example` 为 `.env.development`，按需修改：

- `LLM_API_KEY`：本地开发可填 Mock 代理地址
- `HIS_*` / `EMR_*`：开发环境使用 Mock 适配器
- `LOG_LEVEL=debug`：本地打开调试日志

## 5. 验证环境

```bash
bun run typecheck   # 应无错误
bun run lint         # 应无 error
bun run test:unit   # 现有单测应通过
```

## 6. 常见问题

- **Bun 版本不符**：执行 `bun upgrade`
- **Node 版本不符**：使用 nvm / fnm 切换到 20 LTS
- **提交时 LF 被转 CRLF**：确认 `.gitattributes` 已生效，`git add --renormalize .`
