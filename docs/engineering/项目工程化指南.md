# 健澜科技数智医院智能体 - 项目工程化指南

> 版本：v1.0 · 日期：2026-09-16

## 1. 工程化目标

为健澜科技数智医院智能体提供一套**可重复、可审计、可回归**的研发流水线，覆盖：

- 代码质量门禁（ESLint + Prettier + TypeScript 严格模式）
- 自动化 CI/CD（GitHub Actions）
- 环境与配置管理（多环境配置 + zod 运行期校验）
- 结构化日志与自动脱敏（等保三级要求）
- 错误监控与性能 / 健康检查
- 规范化 Git 工作流

## 3. 常用命令

| 命令 | 作用 |
| --- | --- |
| `bun run dev` | 开发模式 |
| `bun run typecheck` | TypeScript 类型检查 |
| `bun run lint` / `lint:fix` | ESLint 检查 / 自动修复 |
| `bun run format` / `format:check` | Prettier 格式化 / 检查 |
| `bun run test:unit` / `test:integration` | 单元 / 集成测试 |
| `bun run test:coverage` | 覆盖率 |
| `bun run build` | 生产构建 |
| `bun run security:audit` | 依赖安全审计 |
| `powershell -File scripts/ci.ps1` | 本地一键 CI |
