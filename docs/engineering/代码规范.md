# 代码规范（ESLint / Prettier）

> 版本：v1.0 · 日期：2026-09-16

## 1. Prettier 规则（`.prettierrc`）

| 项 | 值 | 说明 |
| --- | --- | --- |
| `printWidth` | 100 | 单行最大宽度 |
| `tabWidth` | 2 | 缩进宽度 |
| `useTabs` | false | 使用空格 |
| `semi` | true | 句尾分号 |
| `singleQuote` | true | 单引号 |
| `trailingComma` | all | 多行对象 / 参数尾逗号 |
| `arrowParens` | always | 箭头函数单参数也带括号 |
| `endOfLine` | lf | 统一 LF |

忽略清单见 `.prettierignore`：`node_modules/`、`dist/`、`coverage/`、`docs/*.md` 等。

## 2. ESLint 规则（`eslint.config.js`，flat config）

### 2.1 启用插件

- `@typescript-eslint`：类型感知检查
- `eslint-plugin-react` / `react-hooks`：React 19 + Ink
- `eslint-plugin-simple-import-sort`：导入自动排序
- `eslint-plugin-security`：安全风险
- `eslint-plugin-n`：Node.js 规范

### 2.2 关键规则

| 规则 | 级别 | 说明 |
| --- | --- | --- |
| `no-unused-vars` / `@typescript-eslint/no-unused-vars` | warn | 忽略 `_` 前缀 |
| `@typescript-eslint/no-explicit-any` | warn | 业务代码尽量使用 `unknown` 或具体类型 |
| `@typescript-eslint/consistent-type-imports` | warn | 强制 `import type` |
| `prefer-const` / `no-var` | warn / error | |
| `eqeqeq` | error | 强制 `===`（`null` 例外） |
| `no-eval` / `security/detect-eval-with-expression` | error | 禁止 eval |
| `no-console` | warn | 仅允许 `warn/error/info/debug`，业务代码应使用 Logger |
| `no-debugger` | error | 禁止 debugger 提交 |
| `simple-import-sort/imports` | warn | 导入自动分组排序 |

### 2.3 医疗领域特别规则

- 业务代码禁止 `console.log`，必须使用 `src/core/logging` 的 `Logger`
- 严禁在源码中硬编码身份证号、手机号（已通过 ESLint 自定义正则提示）
- 患者姓名、身份证、手机号等敏感字段在日志输出时自动脱敏

### 2.4 测试文件放宽

`tests/**`、`*.test.ts`、`testHelpers.ts` 关闭 `no-explicit-any` 与 `no-console`。

## 3. 常用命令

```bash
bun run lint          # 只检查
bun run lint:fix      # 自动可修复问题
bun run format        # Prettier 写回
bun run format:check  # CI 用
```
