## 六、技术架构说明

### DEMO_MODE 短路机制
- `requireAuth` 中间件在 `DEMO_MODE=1` 时自动注入 demo user（`id: 'demo', roles: ['admin']`）
- 所有路由无需 token 即可返回 200
- 所有 DB 查询短路，返回内存 mock 数据

### 路由注册模式
- 每个模块合并为一个 `m{N}Routes.ts` 文件
- `server.ts` 中通过 `import { m{N}Routes }` + `...m{N}Routes` 数组展开注册
- 截至 M230，已注册 40+ 个模块路由文件
