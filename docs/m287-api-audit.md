## 五、审计结论

- **总端点数**：395
- **覆盖业务域**：30+ 个核心域全部有 API 端点
- **前端页面数**：1615 个目录（含大量细分/AI/质控类页面，属前端展示层，不需一一对应后端 API）
- **M287 补充数**：6 个（麻醉/中医/牙科/眼科缺口补强）
- **遗留说明**：前端 1615 个页面目录远多于 BFF 端点数（395），差异主要来自：
  1. 大量 emr-qc-* 质控页面（~200+ 个）属 EMR 质控子模块，共享 emr/* 端点
  2. AI 辅助页面（emr-ai-*）属前端 AI 功能层，调用通用 AI 端点
  3. 专科页面（v5 后缀）属前端多版本迭代，后端统一端点
  4. 非医疗核心域（admin/party/union 等）属行政/党建页面，不属 BFF 医疗业务范围
