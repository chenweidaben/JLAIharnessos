# 健澜AI原生医院操作系统OS

## 使命
让每一次诊疗都沉淀，让系统越用越聪明。

## 不是什么
不是又一个 HIS，不是电子病历的翻新，不是医院信息科的工具集。

## 是什么
是医院的"AI大脑"——每一次挂号、每一张处方、每一次检查、每一笔收费，都成为 AI 的学习样本。医生越用越准，系统越用越聪明。

## 三层架构
```
┌─────────────────────────────────┐
│  TS 前端 BFF（医生工作站）       │  ← 已有的优秀资产
├─────────────────────────────────┤
│  Python AI 层（FastAPI+vLLM）   │  ← 诊疗沉淀闭环
│  NLP纠错 / CDSS / 影像 / 记忆   │
├─────────────────────────────────┤
│  Java 核心交易（Modulith）       │  ← 挂号/收费/医嘱/床位
└─────────────────────────────────┘
```

## 核心闭环
诊疗发生 → 归档 encounter_record（append-only）→ AI 学习反馈 → 下次就诊建议更准

## 对标
- 不是 Oracle Cerner（流程电子化）
- 不是 Epics（记录数字化）
- 是医院的"AlphaGo"——每次诊疗都在训练模型

## 合规底线
- 病历 append-only，不可篡改
- PHI 本地脱敏，不出院
- AI 推理走本地 vLLM，不调用境外大模型
- 达梦信创可替换 PostgreSQL
