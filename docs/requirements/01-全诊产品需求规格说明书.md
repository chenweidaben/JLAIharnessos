## 1. 产品概述

### 1.1 产品定位

健澜科技数智医院智能体是一款面向临床医生的**AI原生临床智能伙伴平台**，核心理念是"从使用AI，到创造自己的临床智能伙伴"。

产品通过超级智能体的记忆、意图识别与工具调度能力，将医生的自然语言需求转化为流程协同，实现从"人找功能"到"功能找人"的转变。医生可通过对话创建并调用自己的专业技能，将个人经验沉淀为可复用的临床AI能力。

> **原文追溯**：产品说明第4段——"全诊5.0通过超级智能体的记忆、意图识别与工具调度能力，将医生的自然语言需求转化为相应的流程协同，实现从'人找功能'到'功能找人'的转变。"

### 1.2 核心价值主张

| 价值维度 | 具体主张 |
|----------|----------|
| **场景化AI** | 不要求医生判断"该打开哪一个功能"，而是从正在开展的工作出发，提供信息采集、整理、提示和协同支持 |
| **医生共建** | 支持医生把专业经验沉淀为可管理、可调用的AI能力，亲身参与AI共建；知识库提供依据，技能库提供方法，医生始终是能力创建者和最终把关人 |
| **工作流闭环** | 将问诊采集、结构化病历、辅助诊疗、患者管理与随访任务连接为持续的诊疗路径，AI参与诊疗前后衔接的关键环节 |
| **质量与合规前移** | 将病历质控提示前移至临床工作流中，针对文书完整性、逻辑一致性及可能存在的风险给出结构化提示 |
| **安全可控** | 支持私有化部署、模型压缩和混合模型调用，在安全、合规和自主可控的边界内服务医疗机构 |

### 1.3 目标用户

| 用户层级 | 目标用户 | 核心诉求 |
|----------|----------|----------|
| **主要用户** | 临床医师（门诊/住院/急诊） | 减少文书负担、获得诊疗决策辅助、提升工作效率 |
| **次要用户** | 科室主任/质控员 | 病历质量管控、诊疗规范落地、科室运营分析 |
| **次要用户** | 编码员/医保管理员 | 病案编码辅助、DRG/DIP预分组、费用合规审核 |
| **次要用户** | 带教老师/教学管理者 | 虚拟病例教学、规培考核、教学资源沉淀 |
| **次要用户** | 临床科研人员 | 病例归集、文献梳理、研究草稿生成 |
| **管理者** | 医院信息化管理者 | 私有化部署、数据安全、权限治理、系统集成 |
| **终端受益者** | 患者 | 更连贯的诊疗体验、更规范的随访管理 |

### 1.4 使用场景

产品覆盖医生日常工作的七大任务现场：

1. **门诊接诊**：问诊录音自动转写、病历草稿生成、辅助诊疗决策
2. **病房查房**：查房记录整理、病程记录生成、患者风险预警
3. **手术围术期**：术前评估、手术记录、术后访视记录
4. **急诊急救**：急诊场景快速信息采集与决策辅助
5. **临床研究**：同类病例归集、文献材料组织、研究草稿形成
6. **教学培训**：虚拟病例模拟问诊、AI带教指导、规培考核
7. **患者管理与随访**：随访任务自动生成、随访话术辅助、患者时间线管理

> **原文追溯**：产品说明第5段——"门诊、病房、手术、急诊急救、科研、教学和患者管理，构成了医生日常工作中不同的任务现场。"

### 7.3 集成约束

1. **数据不出院**：私有化部署模式下，所有患者数据与AI推理在院内完成，不得外传
2. **接口标准化**：优先采用HL7 FHIR、WebService等医疗行业标准接口
3. **权限一致**：与HIS/EMR的权限体系保持一致，避免越权访问
4. **审计可追溯**：所有跨系统数据交互记录审计日志
5. **降级策略**：外部系统不可用时，本系统核心功能（录音转写、病历生成）可独立运行
