## 1. 智能体适用场景分析

### 1.1 AI智能体适用性评估框架

基于产品需求，我们从**任务结构化程度、数据可获得性、决策风险等级、人工重复度**四个维度评估各业务环节对AI智能体的适用性：

| 评估维度 | 高适用性特征 | 低适用性特征 |
|----------|-------------|-------------|
| **任务结构化程度** | 流程明确、输入输出规范、有标准模板 | 高度灵活、无固定流程、需要创造性判断 |
| **数据可获得性** | 有充足的历史数据、指南文献、标准模板 | 数据稀缺、无标准化记录、依赖隐性经验 |
| **决策风险等级** | 低风险辅助性任务、人工复核后生效 | 高风险终局决策、直接影响患者生命安全 |
| **人工重复度** | 高频重复、耗时耗力、易疲劳出错 | 低频复杂、每次情况差异大 |

### 1.3 核心结论

1. **高度适合AI智能体的环节**（★★★★★）：录音转写、病历生成、随访、质控、PPT生成、意图调度——这些环节结构化程度高、人工重复度高、决策风险可控，是智能体落地的首选场景
2. **中度适合的环节**（★★★★☆）：问诊引导、报告解读、风险预警、编码匹配、虚拟教学、科研辅助——需要AI提供分析和建议，但最终判断由人工完成
3. **谨慎应用的环节**（★★★☆☆）：鉴别诊断、诊疗方案、研究草稿——AI仅呈现证据和选项，绝不替代医生/研究者的专业决策
4. **不适合AI独立完成的环节**：终局诊疗决策、有创操作、伦理审批、学术结论——必须由具备资质的专业人员负责

#### AG-01：ADS病历书写智能体

| 项目 | 内容 |
|------|------|
| **智能体名称** | ADS无感病历书写智能体（Auto Documentation System） |
| **对应产品模块** | M01 ADS无感病历自动书写 |
| **核心职责** | 将医生问诊/查房的语音对话、上传的检查报告和既往资料，自动转化为结构化医学文书草稿 |
| **触发方式** | 医生在工作台点击"ADS录音转写"或语音唤醒；诊疗场景自动激活 |
| **输入** | ① 实时音频流（门诊/查房/会诊录音）② 上传的检查报告/照片/既往病历 ③ 患者基本信息 ④ 选择的病历类型（72种之一）⑤ 科室/病种模板 |
| **输出** | ① 结构化病历草稿（按所选文书类型模板）② 转写文本全文 ③ 缺失信息提示清单 ④ 音频文件留存 |
| **调用的医疗工具** | ASR语音识别引擎、医学实体抽取模型、病历模板引擎、RAG知识库检索（模板/指南）、72种文书结构化映射器 |
| **关键能力** | 中文医疗语音识别（保留音频）、多源资料融合、72种文书自动适配、逐段可复核、资料不足主动提示 |
| **性能要求** | 实时转写延迟≤2秒；单份病历生成≤30秒 |
| **原文依据** | 产品说明第6-7段；界面截图image3 |

## 4. 智能体与人工的协作边界

### 4.1 协作原则

健澜科技数智医院智能体严格遵循**"AI辅助、人工决策"**的核心原则：

1. **AI不替代医生**：所有涉及患者诊疗决策的环节，AI仅提供信息、证据、建议和提示，最终判断始终由具备资质的医务人员做出
2. **可追溯可复核**：AI生成的所有内容保留原始依据和推理过程，支持人工逐段复核和修改
3. **风险分级控制**：低风险任务AI可自动完成，中风险任务AI生成+人工确认，高风险任务AI仅提供参考
4. **异常自动升级**：AI遇到超出能力范围或高风险情况时，自动升级给人工处理
